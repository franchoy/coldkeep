## Destination-mode matrix

| Mode | Target identity | Authorized destination | Forbidden fields |
| --- | --- | --- | --- |
| `original` | `physical_file.path` | exact stored path | destination root/path |
| `prefix` | `physical_file.path` | safe relative form beneath destination root | exact destination path |
| `override` | `physical_file.path` | exact requested destination path | destination root |

Validated outcomes:

- original mode writes only to the stored destination path;
- prefix mode returns a destination beneath the resolved prefix root;
- override mode writes only to the exact requested destination path;
- exact output bytes, overwrite semantics, pin cleanup, and catalog
  non-mutation remain intact through the engine boundary.

## Traversal and rooted-path guards

Validated through direct engine, storage, and routed CLI coverage:

- POSIX traversal forms such as `../escape.bin` and
  `nested/../../escape.bin` are rejected;
- backslash traversal forms such as `..\\escape.bin` and
  `nested\\..\\..\\escape.bin` are rejected;
- foreign rooted forms such as `C:\outside\file.bin`,
  `C:/outside/file.bin`, `\\server\share\file.bin`, and
  `//server/share/file.bin` fail closed;
- no file is created outside the prefix root;
- no restore-owned temp file remains after rejection.

## Symlink guards

Validated guards:

- symlinked prefix root rejection;
- symlinked parent beneath a prefix root rejection;
- symlinked override target rejection;
- symlinked override parent rejection;
- original-mode symlink target fails closed;
- original-mode symlinked parent rejection;
- no outside write occurred in any rejected case.

## Production hardening

Expanded regressions exposed two real fail-open defects before the fix:

- `TestRestoreStoredPathOverrideRejectsSymlinkedParentWithoutOutsideWrite`
  initially succeeded and wrote through a symlinked override parent;
- `TestRestoreStoredPathOriginalModeRejectsSymlinkedParentWithoutOutsideWrite`
  initially succeeded and wrote through a symlinked original-mode parent.

The narrow production correction was limited to `internal/storage/restore.go`:

- `validateRestoreWritePath` now calls
  `pathsafe.ValidatePathHasNoSymlinkComponents(absPath)` before the existing
  trusted-root write-path validation.

This preserves prefix-mode containment, continues to allow missing suffix
components, does not broaden any destination-mode semantics, and avoids
following symlinks as a safety decision.

No CLI, engine-request, JSON-shape, backend, schema, migration, snapshot,
remove, GC, or repository-format behavior changed.
