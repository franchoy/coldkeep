## Purpose

Phase 15R2 repairs the structural release-state contract without changing the
candidate product tree, workflow, dependencies, release body, PR metadata, or
live repository state. The prior validator could describe the pre-release
candidate but could not truthfully represent the same immutable tree after a
normal protected merge, an annotated tag, or conditional closure progress.

The versioned opt-in is declared only by the exact pair:

```text
Lifecycle declaration model: immutable-transition-v1
Canonical repository: franchoy/coldkeep
```

Partial or malformed declarations fail closed. Legacy fixture and historical
contracts that omit both fields retain their established behavior.

## Implemented contract

The validator now distinguishes these artifact states without granting an
operation permission or external certificate:

- `merged-pending-final-main-certification`
- `tagged-pending-tag-certification`
- `post-release-closure-candidate`

Normal-main validation checks event identity, exact ordered parents, allowed
ancestry, and tree equality with the immutable second parent. Release PR
validation distinguishes a direct head checkout from a verified synthetic
merge checkout. Tag validation distinguishes the annotated tag object from
its peeled commit and treats tag creation separately from main creation.
Closure validation requires strict tag ancestry and preserves the exact
closure-pending gate. The v1 declaration explicitly rejects
`post-release-closed`; Phase 19T remains the sole terminal authority.

JSON results expose the observed `artifact_state`, fixed non-authorizing
authorization/certification values, a bounded evidence scope, and a stable
ordered obligation list. Local main and tag observations remain artifact-only
evidence. Event fixtures establish parser and topology behavior only; they are
not hosted authentication or future production receipts.

## Regression evidence

The immutable parent implementation was preserved outside the repository and
run against one isolated fixture sequence. Its pre-release positive control
passed while the normal-merge and annotated-tag projections failed with the
old semantic contract. The same frozen probe passes all three projections
with this implementation.

The expanded public-entry-point suite covers valid and invalid declaration
forms, explicit/auto agreement, real normal-merge topology, hosted main event
consistency, synthetic PR checkouts, fork and identity conflicts, tag-object
versus peeled-target semantics, lightweight-tag rejection, conditional
closure, terminal-bypass rejection, exact gate projection, deterministic JSON
vocabulary, and failure output. All test repositories are fresh isolated
fixtures with no remote and all synthetic operations are `TEST_FIXTURE_ONLY`.

At this commit boundary the canonical local gates, attached certification,
and a fresh detached-worktree certification are required to pass before this
record is treated as complete. Their evidence is retained externally; no
hosted run is represented as performed here.
