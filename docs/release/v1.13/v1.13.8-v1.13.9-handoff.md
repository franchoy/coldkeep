# Coldkeep v1.13.8 to v1.13.9 Handoff

**Current release:** `v1.13.8 — Restore / Remove Contract Split and Stored-Path Boundary`
**Next release:** `v1.13.9 — Snapshot Mutation Boundary: Create / Delete / Restore`
**Status:** Activated after v1.13.8 release

## v1.13.8 close-out state

`v1.13.8` now leaves the repository with:

- by-ID restore owned by `Engine.Restore`
- stored-path restore owned by `Engine.RestoreStoredPath`
- by-ID remove owned by `Engine.Remove`
- stored-path remove owned by `Engine.RemoveStoredPaths`
- stored-path CLI restore/remove routed through the engine
- restore destination safety, remove reachability, verification, GC, and
  backend invariants proven without changing public behavior

`v1.13.8` does not activate snapshot mutation through the engine.

## v1.13.9 starting point

`v1.13.9` is now active on `release/v1.13.9`.

The next release should focus on snapshot mutation boundary work only:

- `SnapshotCreate`
- `SnapshotDelete`
- `SnapshotRestore`

## Required ownership decision

`v1.13.9` must decide and stabilize:

- whether snapshot mutation becomes fully engine-owned
- exact request/result contracts for preview and live mutation
- retention-safety and restore/delete refusal boundaries
- how CLI compatibility is preserved while making mutation ownership honest

## Explicit non-goals carried forward

The `v1.13.9` handoff does not authorize:

- repair/recovery routing
- GC redesign
- snapshot-retention policy redesign
- backend-default changes
- schema-version changes unless newly proven necessary
- storage/repository format changes

## Handoff constraint

`v1.13.9` should begin from the truthful `v1.13.8` boundary already documented
in `v1.13.8-boundary-summary.md` rather than re-litigating restore/remove
ownership.

## Activation

The activation conditions have been satisfied:

- v1.13.8 Profile A passed;
- PR #101 was merged;
- post-merge `main` CI passed;
- `v1.13.8` was tagged from `main`;
- the GitHub release was published;
- the release branch was deleted.

Phase 0 for `v1.13.9` is complete, and snapshot mutation work is authorized to
begin with Phase 1.
