## Not-applicable decisions

- AUD-010 and AUD-012 are metadata-only contracts. Codec, compression, and
  storage placement cannot affect their persisted query populations.
- AUD-014's target controls construction of new packed blocks. Legacy
  preservation is directly required and proved, but a mixed repository is not
  a third resolver behavior; it is the already-proved packed construction plus
  unchanged legacy placement.
- AUD-017 init compression applies only to new packed writes. Legacy and mixed
  layouts are therefore not additional init result cells. C5 directly proves
  that existing blocks are not rewritten when compression changes.

Every entry above is `NOT_APPLICABLE_BY_FROZEN_CONTRACT`, never `NOT_TESTED`.
