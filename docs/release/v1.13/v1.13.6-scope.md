# Coldkeep v1.13.6 Scope

**Release:** `v1.13.6 — Catalog Contract Expansion and Backend Parity Review`  
**Branch:** `release/v1.13.6`  
**Status:** In progress

## Purpose

v1.13.6 expands the v1.13 contract-stabilization work from engine-level
validation and invariant ownership into catalog/backend contract review.

The release focuses on the catalog contracts that determine snapshot
membership, logical/physical mapping, placement, restore planning,
reachability, GC eligibility, and SQLite/PostgreSQL parity.

## Release character

v1.13.6 is review-first and docs-first.

Tests may be added only if a narrow, justified catalog/backend contract gap is
confirmed.

Production code changes are out of scope unless a real correctness blocker is
proven by a failing test.

## Primary scope

v1.13.6 reviews:

- snapshot membership contracts
- logical/physical file mapping contracts
- placement and restore-plan catalog assumptions
- reachability and GC eligibility contracts
- SQLite/PostgreSQL schema parity
- SQLite/PostgreSQL query parity
- existing catalog/backend test coverage
- targeted catalog/backend guards only if justified

## Non-goals

v1.13.6 does not introduce:

- schema rewrite
- migration rewrite
- storage format change
- repository format change
- backend default change
- SQLite-only assumption
- PostgreSQL compatibility removal
- daemon/API/UI work
- NAS/cloud/network work
- broad engine routing migration
- public CLI behavior change
- human output change
- JSON output change
- JSON error-envelope change
- exit-code change
- broad refactor

## Backend posture

SQLite compatibility must be preserved.

PostgreSQL compatibility must be preserved.

SQLite-first local direction must not become SQLite-only.

PostgreSQL-backed validation remains mandatory in the final release gate.

No backend default changes are allowed in v1.13.6.

## Expected outputs

v1.13.6 should produce:

- catalog contract inventory
- snapshot membership contract review
- logical/physical mapping contract review
- placement and restore-plan contract review
- reachability and GC eligibility contract review
- SQLite/PostgreSQL parity review
- catalog/backend test coverage classification
- targeted guard decision record
- release summary and v1.13.7 handoff
- final release gate evidence

## Release readiness rule

v1.13.6 is not release-ready until the full `PRE_RELEASE_CHECKLIST.md Profile A`
gate passes and the evidence is recorded.
