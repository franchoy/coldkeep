The dependency declares `go 1.25.0`. Go refuses a read-only module graph when
the main module retains the shorthand `go 1.25`, so the directive is
canonically spelled `go 1.25.0`. This is the initial Go 1.25 language release,
not a language-line or feature-floor increase. Phase 2 remains responsible for
setting the certified `toolchain go1.26.7` and reconciling all documentation.

## Rename-boundary remediation

`windowsRenameBuffer` now:

- encodes the destination before allocation;
- rejects more than 32,767 UTF-16 code units with the deterministic private
  `errWindowsRenameNameTooLong` error;
- allocates exactly the native header plus encoded name bytes;
- uses `unsafe.Slice` only at the validated allocated length; and
- removes the unchecked synthetic `[windows.MAX_LONG_PATH]uint16` cast that
  could panic above its array bound.

Tests cover ASCII and non-BMP strings immediately below, at, and above the
accepted code-unit boundary, validate native header and encoded bytes, and
reject embedded NUL input.
