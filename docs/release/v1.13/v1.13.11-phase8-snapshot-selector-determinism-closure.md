# Coldkeep v1.13.11 Phase 8 — Snapshot Selector Determinism Closure

**Status:** Implementation pending exact-head CI evidence
**Branch:** `release/v1.13.11`

## Implemented scope

- `TestEngineSnapshotSelectorsAcrossBackends` proves equal-time snapshot list
  ordering, inclusive time bounds, label filtering, file-query intersection,
  deterministic repeated reads, and filtered diff ordering.
- `TestEngineSnapshotSelectorErrorsAcrossBackends` proves invalid direct-engine
  regex rejection, pre-cancelled selection, missing snapshot classification,
  and database/container non-mutation.
- Engine query conversion now returns an invalid-request error for malformed
  regexes instead of silently dropping the regex filter.
- CLI diff retains its complete snapshot-domain query, including repeated
  `--path` and `--prefix` selectors, rather than selecting an arbitrary map
  member through the narrower engine seam.
- CLI tree shaping keeps equal-time ID ordering, treats missing parents as
  roots, breaks cycles, and emits duplicate metadata IDs only once.

  `TestEngineSnapshotSelectorsAcrossBackends/postgres` and
  `TestEngineSnapshotSelectorErrorsAcrossBackends/postgres`.
- SQLite quality execution, JSON parser enforcement, and the exact-head

latest/tag/batch-ID selector, label case-insensitivity, wildcard escaping,
locking, schema, or final release-gate completion. BKC-011 remains
`Separate evidence — no parity proof` until the required CI evidence exists.
