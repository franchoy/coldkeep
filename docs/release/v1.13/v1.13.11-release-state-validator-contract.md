# Coldkeep v1.13.11 Release-State Validator Contract

## Applicability

The release-state validator implementation and CKRS rule set remain unchanged.
Its active version-specific inputs for v1.13.11 are the source version, version
test, reusable pre-release checklist, changelog, root and release READMEs,
v1.13.11 trackers, this applicability record, and the reconciliation record.

Phase 0 intentionally produced a temporary branch/version lifecycle mismatch:
the active branch and documents named v1.13.11 while source identity remained
1.13.10. Phase 1 resolves that mismatch by updating source, test, checklist,
changelog, and tracker identity. It does not extend, redesign, or replace CKRS.

The expected development result is:

```json
{"status":"ok","validator":"coldkeep-release-state","state":"development","active_version":"1.13.11","violations":[],"error":null}
```
