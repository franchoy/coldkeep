file and no remote object may change.

governance validator/tests, and Phase 4 evidence only. Historical evidence is

ruleset correction and immutable-release setting. No product behavior change.

tag and source-only release externally. Phase 10 uses only
`release/v1.13.15-post-publication-closure`, preserves its commits in main,
then deletes both zero-unique temporary branches.

Changes outside the applicable phase allowlist require a return to Plan mode.
