# v1.13.0 Scope

## Release Name

`v1.13.0 - Engine Stabilization Baseline & Contract Inventory`

## Scope Statement

v1.13.0 is a documentation-only baseline release. Its job is to inventory the current engine,
catalog, dependency, and compatibility surfaces so later v1.13.x releases can stabilize them
without ambiguity. It must not change runtime behavior, data shape, routing, or implementation.

## Included

- Engine operation inventory.
- Engine request and result inventory.
- `ErrNotImplemented` inventory.
- CLI direct-domain coupling inventory.
- Catalog contract inventory.
- Catalog deferred-method inventory.
- Dependency-direction baseline.
- SQLite/PostgreSQL compatibility baseline.
- Correctness invariant ownership map.
- v1.13.x release train proposal.
- Final release gate record.

## Excluded

- Go behavior changes.
- New engine routing.
- New catalog implementation.
- Schema changes.
- Storage or repository format changes.
- Default DB backend switch.
- SQLite-only assumptions.
- PostgreSQL removal.
- CLI, JSON, or exit-code changes.
- Daemon, API, UI, or v2 implementation.
- Broad refactors.
- Style-only cleanup.

## Guardrails

- No Go files should change during v1.13.0 unless explicitly justified and re-approved.
- No tests should change during v1.13.0 unless a later scoped decision explicitly adds a pure
  dependency-audit script.
- No release document may imply that inventory work already stabilizes or reroutes the engine.
- No release document may imply SQLite-only support or reduced PostgreSQL compatibility.
- No phase may introduce behavior work under the label of cleanup, prep, or refactor.

## Intended Outputs

v1.13.0 should leave behind:

- A complete inventory of current engine operations and contracts.
- A complete inventory of current catalog contracts and deferred methods.
- A baseline map of dependency direction and correctness ownership.
- A documented compatibility baseline for SQLite and PostgreSQL.
- A proposed v1.13.x release train that sequences implementation after inventory.
- A final release gate record showing the release remained inventory-only.
