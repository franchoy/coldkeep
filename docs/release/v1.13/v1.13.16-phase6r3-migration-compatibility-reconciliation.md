chunk occurs in a `file_chunk` recipe whose logical file is referenced by
`snapshot_file`. A whole-dead block has referenced chunks but no chunk retained
by the root union. A partial-live block has both retained and unretained chunks.
Legacy dead-chunk reclamation predicates must exclude snapshot-reachable
chunks. Counter-only assertions must remain counter-only.
