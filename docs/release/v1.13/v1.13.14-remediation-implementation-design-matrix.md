## CK-V1-AUD-001

- **ID:** `CK-V1-AUD-001`
- **CLASSIFICATION:** `CONFIRMED_OPEN_FROZEN`
- **OWNER_PHASE:** 4
- **CURRENT_BEHAVIOR:** Engine derives counters from catalog metadata rather than executed verification stages.
- **FROZEN_CORRECT_BEHAVIOR:** A per-invocation ledger counts distinct verified legacy block rows and packed `storage_block` objects; every successful physical, compressed, logical, or decompression stage is layout-neutral and counted once by block identity.
- **ROOT_CAUSE:** Verification orchestration returns only error state, so Engine reconstructs a false summary afterward.
- **IMPLEMENTATION_STRATEGY:** Record stage completion at execution sites, deduplicate authoritative block keys, return the ledger through maintenance, and map it directly to `VerifyResult`.
- **PRIMARY_SOURCE_FILES:** `internal/verify/**`, `internal/maintenance/verify_command.go`, `internal/engine/default_engine.go`, `internal/engine/types.go`
- **POSSIBLE_HELPER_OR_SEAM:** Private `verify.ExecutionStats` plus a nil stage observer.
- **PUBLIC_API_CHANGE:** NO
- **SCHEMA_CHANGE:** NO
- **STORAGE_FORMAT_CHANGE:** NO
- **ERROR_CONTRACT_CHANGE:** NO
- **BACKEND_RELEVANCE:** both
- **PLATFORM_RELEVANCE:** all
- **CODEC_RELEVANCE:** both
- **COMPRESSION_RELEVANCE:** both
- **LAYOUT_RELEVANCE:** all
- **RACE_RELEVANCE:** Ledger/observer must be invocation-local and race-safe.
- **FAULT_INJECTION_RELEVANCE:** Corrupt and skipped payload fixtures prove no false credit.
- **CANCELLATION_RELEVANCE:** An aborted-before-stage block receives no stage credit.
- **COMPATIBILITY_RISK:** Incorrect counter values change to truthful values; result shape is unchanged.
- **REQUIRED_BASELINE_FAILURE:** Existing fast/standard/deep results count metadata for work not selected or executed.
- **REQUIRED_CANDIDATE_SUCCESS:** Engine counters equal independent stage observations for system/file and legacy/packed/mixed fixtures.
- **PRIMARY_REGRESSION_TEST:** `TestVerifyResultFastCountsOnlyExecutedStages`
- **SECONDARY_CONTRACT_TESTS:** Standard, deep, quarantined, repeated-reference, file-target, and mixed-repository accounting.
- **FORBIDDEN_IMPLEMENTATION_SHORTCUTS:** Catalog-row recounts, packed-only counters, per-chunk double credit, or global hooks.
- **ROLLBACK_OR_PARTIAL_FAILURE_SEMANTICS:** Public result stays zero on verification failure; partial ledger remains internal.
- **DEPENDENCIES:** Phase 3 verification observer/transport.
- **NON_GOALS:** Changing verification levels, hashes, storage formats, or public fields.
