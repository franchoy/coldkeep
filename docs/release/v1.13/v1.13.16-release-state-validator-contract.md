## Topology

Numeric lifecycle phases are contiguous from Phase 0 through Phase 19. Merge,
publication, and closure boundaries are ordered but need not be consecutive;
closure must be the last numeric phase. Phase 17 is the separate read-only
publication-authorization boundary between exact-main certification and
publication execution.

Phase 13A/13B/13C and Phase 19A/19B/19C/19T are level-three operational
subdivisions, not numeric lifecycle phases.

## Progression

- Development has exactly one `Next` phase strictly before Phase 16.
- Pre-release has exactly Phase 16 `Next`.
- Merged-not-tagged and tagged allow exactly one `Next` phase strictly after
  Phase 16 and at or before Phase 18.
- Post-release-pending-closure has exactly Phase 19 `Next`.
- Post-release-closed requires every numeric phase Complete.

All earlier consecutive lifecycle contracts remain valid.
