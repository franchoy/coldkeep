## Release objective

`v1.13.3` cleans and stabilizes read-side contracts for stats, inspect,
snapshot show, and snapshot diff using the `v1.13.2` taxonomy baseline while
preserving public CLI behavior, JSON output, exit codes, routing, schema,
storage format, backend defaults, and PostgreSQL compatibility.

## Scope summary

- release docs created for the read-side contract cleanup
- read-side taxonomy and CLI preservation tests already added in earlier phases
- no production behavior change
- no CLI, JSON, exit-code, or routing change
- no schema, storage, repository-format, or backend-default change
