## 5. Final implementation

`prepareSnapshotRestoreRequest` passes `req.Overwrite` to
`buildSnapshotRestoreOptions`, which sets the existing lower `Overwrite`
field. No Engine filesystem precheck, collision implementation, or duplicate
publication path was added.

The new private `snapshotSelectorInput` adapts both public Engine selector
shapes into `normalizeSnapshotSelector`. SnapshotShow uses it through
`snapshotQueryOrNil`; SnapshotDiff normalizes once and passes that compiled
query into its detailed path; SnapshotRestore adapts its selection through the
same normalizer. The obsolete restore-only query, size, time, regex, set-copy,
and empty-query helpers were removed.

Normalization is invocation-local. Exact paths use
`snapshot.NormalizeSnapshotPath`, which rejects blank, whitespace-padded,
absolute, traversal, and unsafe stored-relative values while converting
Windows separators, permitted `./`, and duplicate slashes. Normalized exact
matches deduplicate internally. Prefixes use the same normalization and must
still identify a directory with trailing `/`; no slash is silently added.

Glob uses `path.Match`, regex is compiled once, negative size bounds and
inverted size/time ranges are invalid, zero is a valid size threshold, and an
empty selector remains nil/match-all. Criteria retain AND-between-families and
OR-within-repeated-family lower matching semantics.

`SnapshotRestoreRequest.Paths` is copied without mutation. Its raw length
continues to define `RequestedPathsCount`, independently of internal
`Selection.ExactPaths` normalization and deduplication.
