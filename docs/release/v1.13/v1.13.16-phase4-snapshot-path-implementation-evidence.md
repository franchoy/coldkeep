## Implemented contract

- `SnapshotCreateRequest` and `SnapshotCreateOptions` own an explicit
  `SelectionBase`.
- The CLI resolves its current working directory once and hands it to the
  Engine. Engine and snapshot-domain code do not infer CWD.
- Empty, whitespace-only, NUL-containing, non-absolute, missing, and
  non-directory capture roots fail through the typed validation/catalog
  boundary.
- Capture roots and existing physical sources use cleaned, symlink-resolved
  canonical identities.
- Create selectors remain relative, normalized member selectors; host-native
  physical resolution and capture-root containment are separate operations.
- Full snapshot creation fails atomically if a candidate is outside the capture
  root.
- Persisted snapshot members are losslessly derived relative to the capture
  root. Member collisions fail closed.
- POSIX source components containing a literal backslash fail with
  `invariant_violation` / `SNAPSHOT_MEMBER_PATH_UNREPRESENTABLE` instead of
  being silently rewritten.
- Exact selector misses retain typed `not_found` behavior. Prefix miss
  accounting remains the frozen Phase 5 work.
- Existing snapshot-relative show/query/diff/restore semantics and legacy rows
  remain CWD-independent and unchanged.
