# Coldkeep v1.13.13 Phase 8 Source/Test Allowlist

**Release:** `v1.13.13 — Final v1.x and v2 Handoff Gate`
**Phase:** `7 — Remediation Design and Test-Contract Freeze`
**Status:** Frozen for Phase 8

## Global rule

A file outside this allowlist may be modified in Phase 8 only for a purely
mechanical dependency caused directly by an approved design, such as a package
rename reference or test fixture registration. Any architectural expansion,
new behavior owner, public-interface change, schema/format change, dependency,
or additional blocker requires **STOP** and Plan-mode review.

`EXPECTED_MODIFY`, `EXPECTED_NEW`, `TEST_MODIFY`, and `TEST_NEW` are directly
authorized. `CONDITIONAL_ONLY` may be used only for the stated condition and
must be explained in the Phase 8 report.
