# Coldkeep v1.13.6 to v1.13.7 Handoff

**From release:** `v1.13.6 — Catalog Contract Expansion and Backend Parity Review`  
**To candidate release:** `v1.13.7 — SQLite-First Repository Portability Baseline`  
**Status:** Draft handoff pending v1.13.6 final release gate  
**Branch:** `release/v1.13.6`

## Handoff purpose

This document captures the recommended next release direction after v1.13.6.

v1.13.6 clarified catalog/backend contracts and concluded that no additional
narrow catalog/backend guards were justified in this release.

The next release should use that clarified contract baseline to advance the
SQLite-first repository portability direction without dropping PostgreSQL
compatibility.

## Recommended v1.13.7 title

```text
v1.13.7 — SQLite-First Repository Portability Baseline
```

## Recommended v1.13.7 goal

Prepare the v1.x line for the v2.x local-first roadmap by making the
SQLite-first repository posture more explicit while preserving PostgreSQL
compatibility and final-gate validation.

## Suggested v1.13.7 scope

Candidate scope:

- SQLite-first repository initialization posture
- repository portability expectations
- local repository bootstrap documentation
- backend default documentation review
- PostgreSQL compatibility gate preservation
- migration/bootstrap compatibility review
- documentation and guard review around local-first assumptions
- no backend default change unless explicitly scoped and validated
- no PostgreSQL compatibility removal

## Non-goals for v1.13.7

Recommended non-goals:

- no v2 daemon/API/UI
- no NAS/cloud/network mode
- no storage format change
- no repository format change
- no schema rewrite
- no PostgreSQL compatibility removal
- no SQLite-only assumption
- no public CLI/JSON behavior change unless explicitly scoped
- no broad engine routing migration

## Context carried from v1.13.6
