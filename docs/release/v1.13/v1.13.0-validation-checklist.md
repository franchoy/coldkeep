# v1.13.0 Validation Checklist

## Phase-Level Validation

- Phase 0: run `git diff --check` and `git status -sb`.
- Phases 1 through 9: run validation proportional to the documentation touched and confirm the
  release remains inventory-only with no Go behavior change.
- Phase 10: run the full release gate and record the actual commands and results before PR.

## Required Local Validation

```bash
git status -sb
git diff --check
gofmt -l $(git ls-files '*.go')
go vet ./...
go test -count=1 ./...
go test -race -count=1 ./...
golangci-lint run ./...
scripts/audit_ci_enforcement.sh
```

## No-Go Checks

- No Go files changed unless explicitly justified.
- No tests changed unless a later scoped decision explicitly approves a pure dependency-audit
  script.
- No generated root artifacts committed.
- No schema or migration changes.
- No CLI behavior changes.
- No JSON output changes.
- No exit-code changes.
- No storage or repository format changes.
- No default backend behavior changes.
- No engine routing changes.
- No catalog implementation changes.
- No CI behavior changes.
- No script changes.

## Documentation Checks

- v1.13 docs state that v1.13 starts after v1.12.3 completion.
- v1.13 docs state that engine contract stabilization, catalog contract stabilization,
  dependency-direction hardening, engine-level invariant ownership, SQLite-first local portability
  preparation, and PostgreSQL compatibility preservation are the release-train goals.
- v1.13.0 docs clearly say the release is baseline and inventory only.
- v1.13.0 docs clearly say there is no behavior change.
- Excluded scope clearly blocks implementation, refactor, routing, backend-switch, and v2 work.
- The v1.13.0 release gate records actual commands and actual results before PR.

## Release Gate Recording Requirements

- Record `git status -sb` before and after the final validation run.
- Record the exact command lines executed for the required local validation suite.
- Record pass/fail outcomes for each command and explain any follow-up needed before PR.
- Confirm again at release gate time that no Go files changed unless explicitly justified.
