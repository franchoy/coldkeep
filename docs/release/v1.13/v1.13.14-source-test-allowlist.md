# v1.13.14 Source and Test Allowlist

**Phase:** 2 — prospective owner-phase scope freeze
**Rows covered:** 21/21

Paths below are ceilings, not instructions to edit every listed file. A newly
discovered required package, public API, schema, migration, storage-format,
workflow, dependency, or governance change is a hard stop for owner review.

## Phase 3 — deterministic seams only

Allowed:

- `internal/verify/**`: nil-by-default per-invocation stage observer/ledger transport;
- `internal/maintenance/gc.go` and focused tests: private GC options carrying
  `fsx.FS` and dispatch observation, without scheduling or behavior change;
- `internal/storage/context.go`, restore implementation, and restore seam tests:
  per-StorageContext hooks replacing mutable restore globals;
- `internal/engine/doctor.go` and Doctor tests: context-aware private callbacks;
- `internal/fsx/faultfs/**`: add deterministic `OpTruncate`;
- existing Store interleaving and writer test utilities where no production
  behavior changes.

Not allowed: public fields/types, global hooks, a mocking framework, remediation,
schema, storage bytes, CLI, JSON, workflows, dependencies, or Phase 4+ tests
claiming closure.

## Phase 4 — CK-V1-AUD-001

Allowed: `internal/verify/**`, `internal/maintenance/verify_command.go`, Engine
Verify projection/types, and focused verification Engine/maintenance tests.
Legacy, packed, mixed, level, target, skipped, and quarantine fixtures are
allowed. No verification-level, hash, format, CLI, or schema change.

## Phase 5 — CK-V1-AUD-002

Allowed: affected Engine adapters and Doctor composition; context-aware lower
boundaries in `internal/storage`, `internal/maintenance`, and narrowly required

function wrappers may remain as compatibility delegates. No unrelated context
refactor or already-correct operation rewrite.

## Phase 6 — CK-V1-AUD-007

finalization/error-composition helper, injected writer/finalization tests, and
existing LocalWriter/SimulatedWriter contract tests. No duplicate LocalWriter

## Phase 7 — CK-V1-AUD-008

quarantine helpers, `internal/fsx/faultfs` consumers, and focused fault/state

## Phase 8 — CK-V1-AUD-006 and CK-V1-AUD-009

## Phase 13 — CK-V1-AUD-015, CK-V1-AUD-016, CK-V1-AUD-017

## Phase 14 — CK-V1-GATE-001 through CK-V1-GATE-004

Allowed:

No product Go behavior, workflow topology, governance mutation, benchmark
