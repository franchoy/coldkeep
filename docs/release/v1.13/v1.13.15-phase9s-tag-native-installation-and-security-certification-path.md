## Tag-native public installation contract

The existing blocking Linux, macOS, and Windows matrix retains Go 1.26.7,
GOTOOLCHAIN=local, GOPROXY=direct, GOWORK=off, CGO/native compiler proof, no
checkout, and Required Gate ownership.

Non-tag events continue to select the authoritative same-repository PR head
SHA or exact triggering SHA. Module Origin.Hash must equal that SHA.

Tag events instead select the event ref name as the semantic Go query. Each
platform independently runs `git ls-remote` against the public repository for
both the ordinary tag ref and its mandatory `^{}` peeled ref. Exactly one of
each must exist and both object IDs must be full lowercase SHA-1 identities.
A lightweight tag therefore fails closed. The peeled public commit becomes
EXPECTED_ORIGIN_SHA; no github.sha or module-self-derived fallback is allowed.

The Go module version must equal the tag query, Origin.Hash must equal the
independently peeled commit, the public install must use that semantic query,
the binary must report `coldkeep version 1.13.15`, and build metadata must
name the module at the resolved version. Step summaries record only safe
identity and toolchain evidence.

## Tag CodeQL contract

## Fail-closed enforcement

The CI enforcement audit requires the three-platform matrix, event-derived
query selection, independent public tag object and peel resolution, Unix and
Windows expected-origin equality, semantic-version equality, selected-query
module resolution and installation, binary/build metadata identity, absence
of checkout and failure suppression, Required Gate ownership, CodeQL tag
coverage, all three CodeQL languages, and the aggregate dependency/result
contract.

Deterministic mutation tests reject SHA-only tag handling, missing tag-event or
ref-name selection, missing public resolution or peel proof, self-derived
origin authority, missing Unix or Windows Origin.Hash equality, missing
semantic-version proof, wrong go-list or go-install query, checkout,
continue-on-error, broad failure suppression, CodeQL trigger/language loss,
and a missing or nonblocking aggregate.
