# Coldkeep v1.13.15 Scope

**Release:** `v1.13.15 — Final v1.x Security, Reproducibility, and Operational Closure`
**Status:** Active
**Branch:** `release/v1.13.15`

## Objective

Close v1.x on a supported, patched, vulnerability-scanned toolchain; repair
the two Windows native-string defects; make clean-clone development and
source-only installation reproducible; reconcile current authority; and
complete enforceable tag and immutable-release governance.

## Current phase

Phases 0–3 are Complete. Phase 4 is Next: Governance and Authority
Reconciliation. Phases 5–10 are Not started.

## Frozen baselines

- Language floor: `go 1.25`.
- Certified toolchain: Go 1.26.7 with `GOTOOLCHAIN=local`.
- Windows dependency: `golang.org/x/sys v0.44.0`.
- Scanner: `golang.org/x/vuln/cmd/govulncheck@v1.7.0` in ordinary mode.
- Distribution: source-only; no prebuilt binaries.
- Source-install OS families: Linux, macOS, Windows.
- Product images: Linux `amd64` and `arm64`.
- Image identities: exact semantic tags plus registry-resolved official index
  digests; no Phase 0 digest or Alpine patch freeze.

## Root invariants

1. Windows native strings are length-safe and cannot panic at rename limits.
2. Every release-critical path uses one supported, patched, scanned toolchain.
3. Repository and hosted release authority are current, truthful, and
   enforceable.
4. A clean clone can be developed, built, and installed through documented,
   tested contracts.

## Exclusions

No v2 implementation, SQLite-first product/default behavior, public API
expansion, storage schema or format change, migration, broad refactor,
prebuilt-binary distribution, historical v1.13.14 rewrite, or weakening of tag
creation protection is authorized.

Scope expansion, unexpected dependency movement, identity drift, private
security impact, ambiguous registry identity, or unsupported governance
semantics requires a return to Plan mode.
