# v1.13.17 Release-State Validator Contract

**Merge-complete phase:** 5
**Tag/publication phase:** 8
**Post-publication closure phase:** 9
**Lifecycle declaration model:** immutable-transition-v1
**Canonical repository:** franchoy/coldkeep
**Predecessor disposition model:** failed-publication-predecessor-v1

## Selected predecessor

The exact ordered predecessor disposition selects the immediate dated
`[failed-publication-predecessor]` changelog entry. It is not an ordinary
operationally closed predecessor and cannot fall back to that route.

## Exact tag identity

For the selected active-version annotated tag, raw runtime SHA and event
`after` may independently be the annotated tag object or its unique direct
commit target. Both must resolve to checkout HEAD. The evaluator rejects
lightweight, nested, alternate, missing, replaced, grafted, shallow, or
alternate-object-store observations and requires a normal ordered two-parent
tree-preserving merge.

## Diagnostic contract

Applicable release PR and tag-push paths emit
`coldkeep-release-state-diagnostic/v2`. A reached tag evaluation uses the
ordered 34-predicate inventory, one bounded event read, explicit unavailable
observations, a 1,048,576-byte event limit, a 262,144-byte output limit, mode
0600, exclusive installation, and no full environment or event payload.

All validator outputs are structural and non-authorizing. Hosted
certification, merge, tag, publication, and terminal closure remain external.
