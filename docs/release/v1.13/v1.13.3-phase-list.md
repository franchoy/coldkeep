envelope, and exit-code behavior must remain stable and must not leak taxonomy
helper names. Backend/dependency finding: current behavior is expected to stay
backend-equivalent, public engine stats types are backend-neutral by test, and
renderer dependency on the observability result type remains provisional for
later review. Production code unchanged. Tests unchanged. Scripts and CI
unchanged. Runtime behavior unchanged. Next phase: Phase 3 inspect contract
cleanup map.
