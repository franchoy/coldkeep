## G6 investigation

The original recorded failure was:

```text
verifyChunkBlockRefs:
chunk 3 has both packed and legacy mappings outside migration companion contract
```

Phase 0 does not classify that event as merely flaky.

- The original failure was not reproduced deterministically.
- Permanent failure-state capture was added so future recurrences preserve
  database and container diagnostics.
- Deterministic controlled-interleaving coverage was added inside the storage
  package and exercised remotely against PostgreSQL.
- PostgreSQL retry/CAS coverage is now required by CI.
- Each deterministic PostgreSQL subcase creates its own isolated database and
  fresh input fixture.
- Claim/reuse, visibility, companion, retry, rollback, commit, idempotence,
  and cleanup boundaries are now covered.

### Deterministic PostgreSQL G6 evidence

All six deterministic subcases passed:

- `plain/packed_metadata`
- `plain/legacy_companion`
- `plain/retry_path_remains_packed`
- `aes-gcm/packed_metadata`
- `aes-gcm/legacy_companion`
- `aes-gcm/retry_path_remains_packed`

Each subcase used a fresh isolated PostgreSQL database and input fixture.

### Proven rebuild-cleanup defect

Rebuild cleanup could delete packed child metadata while leaving an unreferenced
`storage_blocks` row.

The correction is:

- candidate-scoped;
- transactional;
- protected by `NOT EXISTS`;
- shared-reference safe;
- rollback safe;
- idempotence covered; and
- directly asserted before full verification in realistic scenarios.

This proven rebuild-cleanup defect is recorded separately from the original G6
packed-plus-legacy event. Phase 0 does not claim that the cleanup defect caused
the original invalid mapping report.

### Residual risk

The original invalid packed-plus-legacy mapping was not reproduced
deterministically. The investigation identified and corrected a related
rebuild-cleanup defect, added permanent failure-state capture, and introduced
deterministic coverage across the suspected transaction and cleanup boundaries.
A low residual risk remains for an unobserved environment-specific transition,
and future recurrence will preserve diagnostic artifacts.
