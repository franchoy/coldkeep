## Inherited findings

### `CK-1139-P0-01 — Outer symlink-prefix restore compatibility`

- Original defect:
  restore rejected legitimate system-managed aliases above the trusted root
  because validation walked the full absolute destination path before
  meaningful boundary selection.
- Invariant restored:
  aliases above the trusted root are allowed; symlinks at the trusted root,
  below the trusted root, and at existing target paths remain rejected.
- Implementation summary:
  restore now validates explicit or derived trusted roots and then checks
  existing descendant components below that root.
- Principal files changed:
  `internal/pathsafe/pathsafe.go`,
  `internal/storage/restore.go`,
  `internal/engine/default_engine_routing_helpers.go`,
  `internal/engine/restore_stored_path.go`,
  `internal/snapshot/snapshot.go`
- Principal regression tests:
  `internal/storage/restore_trusted_root_test.go`,
  `internal/engine/restore_engine_test.go`,
  `internal/engine/restore_stored_path_test.go`,
  `internal/snapshot/snapshot_test.go`,
  `internal/pathsafe/pathsafe_test.go`

### `CK-1139-P0-02 — Stored-path fail-fast summary compatibility`

- Original defect:
  stored-path batch remove finalized summaries against request length, so
  fail-fast batches could report totals larger than emitted item results.
- Invariant restored:
  `summary.total == len(results)` and unvisited trailing targets are absent,
  not skipped.
- Implementation summary:
  remove-stored-path summary counts now derive only from emitted items; request
  length no longer backfills skipped totals after fail-fast.
- Principal files changed:
  `internal/engine/remove_stored_paths.go`,
  `internal/engine/default_engine.go`,
  `internal/engine/remove_stored_paths_batch_test.go`
- Principal regression tests:
  `internal/engine/remove_stored_paths_batch_test.go`

### `CK-1139-P0-03 — All-invalid stored-path initialization ordering`

- Original defect:
  invalid-only stored-path batch remove still initialized repository storage
  before engine-owned blank/duplicate classification.
- Invariant restored:
  blank-only and duplicate-only batches return deterministic terminal reports
  without repository initialization.
- Implementation summary:
  engine-owned preflight now classifies raw targets before dependency checks,
  and the CLI short-circuits terminal invalid-only results through the normal
  batch reporter.
- Principal files changed:
  `internal/engine/remove_stored_paths.go`,
  `internal/engine/default_engine.go`,
  `cmd/coldkeep/main.go`
- Principal regression tests:
  `internal/engine/remove_stored_paths_core_test.go`,
  `cmd/coldkeep/stored_path_engine_routing_test.go`

### `CK-1139-P0-04 — Required cross-platform enforcement`

- Original defect:
  a native `cross-platform` CI job existed but was not part of the required
  aggregate gate, the release branch had no direct branch-push remote
  validation path, and the local CI audit did not enforce that dependency or
  its success condition.
- Invariant restored:
  `ci-required` cannot pass unless native cross-platform validation succeeds,
  and `release/**` branches now have direct CI and CodeQL validation without a
  temporary PR.
- Implementation summary:
  `cross-platform` is now a direct dependency of `ci-required`, the aggregate
  success assertion explicitly checks its result, the native workflow runs the
  trusted-root/alias restore suites, release-branch pushes now trigger CI, an
  in-repo CodeQL workflow replaces the unmanaged branch gap, and the CI audit
  mechanically verifies that policy.
- Principal files changed:
  `.github/workflows/ci.yml`,
  `.github/workflows/codeql.yml`,
  `scripts/audit_ci_enforcement.sh`,
  `scripts/audit_ci_enforcement_test.go`
- Principal regression tests:
  `scripts/audit_ci_enforcement_test.go`
