## Supported upgrade-path decision

The executable supported evidence includes SQLite pre-v6/current mapping and
subsequent versioned migrations through v16, plus PostgreSQL legacy v5/pre-v6,
v7, and v11/current-schema application. The audit found no valid supported
repository that can reach version 16 while retaining a weaker
correctness-critical constraint, index, default, foreign-key action, or
metadata invariant.

Differences that cannot arise through current dispatch or a supported fixture
remain historical/maintenance evidence. They are not promoted into artificial
v1 blockers.
