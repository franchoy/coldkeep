# Coldkeep v1.13.17 — Annotated-Tag Certification Recovery

Coldkeep v1.13.17 is a source-only release with no custom assets. It repairs
release tooling and governance after the v1.13.16 failed publication while
preserving the inherited product behavior and correctness work from that
predecessor.

This recovery release corrects exact annotated-tag and direct-target identity
handling, adds bounded release-state diagnostics, accepts both consistent
release-branch creation and update events, and strengthens CI and governance
checks around those contracts.

The v1.13.16 public tag remains an immutable failed-publication predecessor:
its required tag certification did not complete and no GitHub Release was
published for it. v1.13.15 remains the published stable immutable baseline.

The release does not change the inherited storage format, repository format,
schema, catalog behavior, restore, garbage collection, verification, database
compatibility, or public CLI contracts. SQLite and PostgreSQL support remains
within the existing documented v1 bounds, and legacy and packed storage
behavior remains aligned.
