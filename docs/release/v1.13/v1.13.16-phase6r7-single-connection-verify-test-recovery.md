Preserve the original regression invariant: real packed byte-level deep
verification must complete with exactly one SQLite connection, without
self-starvation, and a deliberately reintroduced sole-connection starvation
must terminate through a bounded operation context. Increasing the connection
limit, weakening byte verification, or relying only on process termination is
forbidden.

Only `internal/verify/verify_system_single_connection_test.go` may change. The
existing test name remains and uses four controlled environment variables:

```text
COLDKEEP_VERIFY_SINGLE_CONNECTION_MODE
COLDKEEP_VERIFY_SINGLE_CONNECTION_DB_PATH
COLDKEEP_VERIFY_SINGLE_CONNECTION_CONTAINERS_DIR
COLDKEEP_DB_OPERATION_TIMEOUT_MS
```

Empty mode is the parent. It creates stable paths beneath one `t.TempDir`,
sanitizes all controlled variables, and invokes the exact test selector in
`fixture`, `success`, and `blocked` order. Each subprocess has a 10-second
outer hang bound, captures combined output, and must finish successfully; an
outer deadline is always failure.

The fixture subprocess omits the timeout variable before initialization,
requires `db.DefaultOperationTimeout() > 250*time.Millisecond`, uses ordinary
pool limits, applies SQLite pragmas, ensures current schema, writes deterministic
non-empty source data, and stores it through real plain-codec
`storage.StoreFileWithStorageContextAndCodecResult`. Store owns finalization.
The child requires at least one `storage_blocks` row, closes resources, and
leaves the supplied DB and containers intact.

The success subprocess initializes with exactly 250 ms, opens the completed
fixture, sets `MaxOpenConns(1)` and `MaxIdleConns(1)`, applies pragmas, proves
the configured limit and packed block, and invokes only
`VerifySystemDeepWithContainersDir`. It performs no schema, Store, or
finalization work and requires nil error.

The blocked subprocess has the same completed-fixture and 250 ms setup. After
proving the packed block, it acquires and retains the sole `*sql.Conn`, proves
the one-open/one-in-use/zero-idle pool state, invokes deep verification, and
requires `errors.Is(err, context.DeadlineExceeded)`. It must release the
connection and exit normally before the outer bound; an outer kill, retry,
sleep, message-only assertion, or unrelated error fails the test.
