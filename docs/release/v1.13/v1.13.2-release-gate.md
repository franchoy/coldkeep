## Boundary protection summary

- `engine.ErrNotImplemented` remains stable.
- `engine.IsUnsupported` recognizes wrapped `engine.ErrNotImplemented`.
- `catalog.ErrNotImplemented` remains stable.
- `catalog.IsDeferred` recognizes wrapped `catalog.ErrNotImplemented`.
- `engine.IsUnsupported(catalog.ErrNotImplemented)` is false.
- `catalog.IsDeferred(engine.ErrNotImplemented)` is false.
- unsupported active engine modes remain unsupported.
- malformed engine requests are not unsupported.
- CLI JSON does not expose taxonomy helper names or taxonomy fields.
- CLI exit-code behavior remains unchanged.
