# v1.13.0 Phase List

## Phase 0 - Scope Lock and Release Folder Baseline

Objective: create the v1.13 release folder, lock inventory-only scope, and define the validation
baseline for the rest of v1.13.0.

Files expected to be touched:

- `docs/release/v1.13/README.md`
- `docs/release/v1.13/v1.13.0-scope.md`
- `docs/release/v1.13/v1.13.0-phase-list.md`
- `docs/release/v1.13/v1.13.0-validation-checklist.md`

Explicit non-goals:

- Go code changes.
- Test changes.
- Schema or migration changes.
- Root README edits.
- Any inventory execution beyond defining the release plan.

Acceptance criteria:

- The v1.13 release folder exists with the four baseline documents.
- The docs state that v1.13 starts after v1.12.3 completion.
- The docs state that v1.13.0 is inventory-only and must not change runtime behavior.
- The excluded scope blocks implementation, refactor, backend-switch, and routing work.
- `git diff --check` is clean and no Go files changed.

## Phase 1 - Engine Operation Inventory

Status note: complete. Inventory recorded in
`docs/release/v1.13/v1.13.0-engine-operation-inventory.md`.

Objective: document every engine operation currently exposed or implied by the existing codebase.

Files expected to be touched:

- `docs/release/v1.13/v1.13.0-engine-operation-inventory.md`

Explicit non-goals:

- Adding, removing, or renaming engine operations.
- Introducing engine dispatch or routing changes.
- Changing CLI behavior to fit the inventory.

Acceptance criteria:

- Every known engine operation is listed with its current owner and call path.
- Direct, indirect, and deferred operations are distinguished.
- Gaps, ambiguities, and duplicates are recorded without implementation changes.
