domain packages. The active engine interface remains read-oriented (Stats, Inspect,

## Remaining Risk

- v1.11.0 is a facade baseline, not a full engine extraction. Only `stats` is actively
  routed through the engine. Inspect and verify remain on direct paths.
- Mutating candidates (`Store`, `Restore`, `Remove`, `SnapshotCreate`, `SnapshotRestore`,
  `SnapshotDelete`, `GarbageCollect`, `Repair`, `Recover`) are inactive and require
  explicit later activation in v1.12+ phases.
- The active `Engine` interface (`Stats`, `Inspect`, `Verify`) is provisional until v1.13.
- PostgreSQL runtime compatibility suite was not run locally in Phases 6–7; no
  backend-specific production code was changed, and existing CI/DB matrix remains
  the PostgreSQL compatibility authority.
- The `TestEngineActiveInterfaceRemainsReadOriented` guard will fail immediately if
  any mutating method is accidentally added to the `Engine` interface before an
  explicit activation phase.
