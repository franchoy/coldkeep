# v1.10.1 Matrix Inventory

Status: In progress  
Owner phase: v1.10.1 Phase 1 — Extract v1.10.1 Matrix Rows

## Release

v1.10.1 — CLI Correctness & Contract Stabilization

## Purpose

This document records the remediation matrix rows selected for v1.10.1.

v1.10.1 is limited to CLI and JSON contract stabilization.

This inventory is the source of truth for the implementation phases that follow.

## Selection Rules

A matrix row belongs to v1.10.1 if it primarily concerns one of:

- unexpected positional arguments
- CLI arity validation
- CLI value flags accepting another flag token as value
- boolean flags treating explicit `false` as `true`
- duplicate singleton flags
- JSON shorthand consistency
- JSON mode and output-mode contract
- mixed human output in machine-readable mode
- validation before repository initialization where the defect is caused by CLI misuse

## Exclusion Rules

A matrix row does not belong to v1.10.1 if the fix primarily requires:

- packed-storage internals
- GC, refcount, or reachability logic
- restore or recovery internals
- filesystem abstraction
- filesystem fault injection
- cross-platform CI expansion
- Codacy hard blocking
- dependency or toolchain upgrade
- repository format change
- engine extraction
- broad CLI redesign
- unrelated refactor

## Phase 1 Boundary

Phase 1 identifies inventory only.

Phase 1 does not:

- implement fixes
- close issue rows
- close remediation-matrix rows
- change issue or matrix status
- add closure proof
