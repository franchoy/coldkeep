## New Tests (Phase 9)

### `TestContainerFilesystemEquivalenceDefaultAndNoop`

File: `internal/container/container_seam_test.go`

Head-to-head equivalence test. Writes the same payload (`"phase9-container-equivalence"`) with two independent `LocalWriter` instances: one with `fsx.Default()` (the initial field value) and one with `w.fs = fsx.NewNoop(fsx.Default())`. Both use separate `t.TempDir()` directories and separate in-memory SQLite databases opened via `openSeamTestDB`. After finalization, reads back the written bytes from both containers at the reported placement offset and asserts `bytes.Equal(defaultBytes, noopBytes)`, proving the seam is byte-for-byte behavior-preserving through `MkdirAll`, `OpenFile`, `Stat`, and `Sync` operations.

### `TestGCFilesystemEquivalenceDefaultAndNoop`

File: `internal/maintenance/gc_seam_test.go`

Head-to-head equivalence test. Creates two files (`dead-equiv-default.bin` and `dead-equiv-noop.bin`) in the same `t.TempDir()`. Deletes `dead-equiv-default.bin` via `removeContainerFileWithFS(fsx.Default(), pathDefault)` and `dead-equiv-noop.bin` via `removeContainerFileWithFS(fsx.NewNoop(fsx.Default()), pathNoop)`. Asserts both are absent (`os.IsNotExist`) in a single test function, proving both `fsx.Default()` and `fsx.NewNoop(fsx.Default())` produce the same observable outcome (file absent) through the GC physical-delete seam.
