# v1.10.10 Phase 1 — Cross-Platform Validation Prompt & Support Contract

Status: Complete

## Purpose

Phase 1 defines the v1.10.10 cross-platform support contract and validation prompt before implementation begins.

## Core Invariant

v1.10.10 must validate and document Coldkeep behavior across supported platforms without claiming unsupported behavior, weakening correctness guarantees, or introducing platform-specific runtime hacks.

## Support Contract Summary

v1.10.10 targets validation on:

* Linux / Ubuntu;
* macOS where feasible;
* Windows where feasible.

The release must avoid claiming full support beyond what CI and tests prove.

## Risk Register Summary

Initial platform risks include:

* Windows path separators and drive paths;
* Windows rename/overwrite behavior;
* Windows file locking;
* POSIX permission mismatch on Windows;
* shell script portability;
* macOS permission/timestamp differences;
* case sensitivity assumptions;
* symlink behavior;
* timestamp precision;
* SQLite locking behavior.

## Scope Confirmation

Phase 1 is docs-only.

Phase 1 does not change:

* runtime behavior;
* tests;
* CI;
* scripts;
* dependencies;
* repository format;
* container format;
* CLI behavior.
