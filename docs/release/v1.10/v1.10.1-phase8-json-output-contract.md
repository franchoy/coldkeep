# v1.10.1 Phase 8 - JSON Output Contract Validation

Status: Complete

## Purpose

Phase 8 validates machine-readable JSON output contract behavior for scoped JSON commands.

The expected invariant is:

> When JSON mode is selected, command stdout remains machine-readable JSON output with no mixed human text, and diagnostics remain on stderr.

## Scope

Included:

- JSON-mode stdout contract checks for `stats`, `inspect`, and `simulate gc`
- JSON-mode usage-error contract checks (stdout remains empty; stderr remains JSON-only)
- startup recovery event separation (stderr) validation for JSON mode

Excluded:

- JSON shorthand routing behavior, already covered by Phase 7
- unexpected positional argument handling, already covered by Phase 3
- value-flag token handling, already covered by Phase 4
- boolean explicit false handling, already covered by Phase 5
- duplicate singleton handling, already covered by Phase 6
- pre-stateful validation ordering, handled in Phase 9
- storage, GC, packed-storage, restore/recovery internals
- CI workflow changes
- dependency/toolchain changes

## Implementation Summary

Phase 8 adds explicit contract tests for JSON purity and channel separation.

| Contract Area | Behavior | Test coverage |
|---|---|---|
| JSON-mode success payloads | stdout emits exactly one JSON object line for scoped commands | `TestJSONModeStdoutIsSingleObjectForStatsInspectSimulate` |
| Startup recovery channel split | startup recovery remains JSON event stream on stderr for startup-recovery commands | `TestJSONModeStdoutIsSingleObjectForStatsInspectSimulate` |
| JSON-mode usage errors | stdout stays empty, stderr remains JSON-only (startup event + structured error where applicable) | `TestJSONModeUsageErrorKeepsStdoutEmptyAndStderrJSONOnly` |
| Generic JSON parse-failure behavior | JSON usage errors are emitted as single structured JSON objects | `TestRunCLIDoctorJSONParseFailureEmitsSingleJSONError` |

No runtime production code changes were required in this phase; existing behavior satisfied the tightened output-contract assertions.
