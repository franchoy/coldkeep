# v1.10.6 Phase 0 — Baseline & Scope Declaration

Status: Complete

## Purpose

Phase 0 declares the v1.10.6 release scope and records the baseline state before implementation work begins.

v1.10.6 is a CI / Codacy / Copilot workflow hardening release.

## Core Invariant

v1.10.6 must improve CI/Codacy/Copilot release discipline without introducing product behavior changes, architecture extraction, style-only blocking, or noisy gates.

## Release Scope

Included:

- audit existing Copilot instructions and prompt files
- add CI-specific Copilot instructions if missing
- add critical-path coverage prompt if missing
- document Codacy passive-mode policy
- document scanner suppression / acceptance / deferral policy
- document CI/Codacy release-gate boundaries
- validate that CI/Codacy/Copilot workflow changes stay correctness-focused
- keep Codacy as signal, not authority

Excluded:

- production behavior changes
- product features
- engine extraction
- catalog abstraction
- default database backend changes
- SQLite-only or PostgreSQL-removal assumptions
- hard Codacy quality gates
- style-only blocking
- CodeRabbit adoption
- mutation testing
- full filesystem fault injection
- global coverage blocking
