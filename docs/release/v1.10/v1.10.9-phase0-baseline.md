# v1.10.9 Phase 0 — Baseline & Scope Declaration

Status: Complete

## Purpose

Phase 0 establishes the release-control baseline for v1.10.9.

v1.10.9 is the filesystem fault-injection Phase 1 release. Its purpose is to add deterministic, test-only filesystem failure scenarios on top of the behavior-preserving filesystem seams introduced in v1.10.8.

## Core Invariant

v1.10.9 must prove that deterministic filesystem failures do not cause silent corruption, unsafe metadata, broken restore, unsafe GC, or unrecoverable repository state.

## Baseline Assumption

v1.10.9 starts after v1.10.8 is released and merged into `main`.

v1.10.8 introduced:

- internal filesystem abstraction package;
- OS-backed adapter;
- no-op behavior-preserving wrapper;
- restore seam;
- container seam;
- recovery/quarantine seam;
- GC delete seam;
- equivalence tests.

v1.10.9 builds on that release-control and seam foundation.
