# v1.10.1 Exclusion Notes

Status: Complete  
Owner phase: v1.10.1 Phase 1 — Extract v1.10.1 Matrix Rows

## Purpose

This document records matrix rows that were considered during v1.10.1 extraction but excluded, deferred, or marked as needing split.

v1.10.1 is intentionally limited to CLI and JSON contract stabilization.

## Excluded / Deferred / Needs-Split Rows

See: `docs/release/v1.10/v1.10.1-matrix-inventory.csv`

Rows with decisions other than `include` are not part of v1.10.1 implementation unless later explicitly re-scoped.

**Decision categories:**

- **exclude**: Row falls outside v1.10.1 scope entirely (15 rows)
- **defer**: Row related to CLI/JSON but intentionally moved to later v1.10.x minor release (7 rows)
- **needs-split**: Row partially in v1.10.1 scope; part belongs elsewhere (4 rows)

## Scope Protection

Rows are excluded when they primarily require:

- packed-storage changes
- GC/refcount/reachability changes
- restore/recovery internals changes
- filesystem abstraction
- dependency/toolchain work
- Codacy enforcement
- CI expansion
- broad refactor
- engine extraction

## Implementation Rule

If implementation later appears to require touching an excluded domain, **stop and update the scope decision before continuing**.

Do not silently accept scope drift. Explicit re-scoping via Phase 1 review is required.
