# v1.10.7 Phase 2 — Coverage Script Report Mode

Status: Complete

## Purpose

Phase 2 adds the initial critical-path coverage reporting script for v1.10.7.

The script is report-only. It provides coverage visibility but does not enforce thresholds.

## Core Invariant

Phase 2 must add coverage visibility without introducing threshold enforcement, global coverage gates, CI workflow changes, product behavior changes, or broad test/code refactors.

## Added Script

```text
scripts/critical_coverage.sh
```

## Supported Mode

```bash
scripts/critical_coverage.sh --report
```

Optional CSV output:

```bash
scripts/critical_coverage.sh --report --csv-output <path>
```

## Phase 2 Behavior

The script:

* reads `docs/release/v1.10/v1.10.7-critical-package-inventory.csv`;
* validates required inventory columns;
* rejects duplicate tracked packages;
* selects Go packages from `internal/**` and `cmd/**`;
* runs `go test -covermode=atomic -coverprofile=...`;
* runs `go tool cover -func=...`;
* prints a critical package coverage summary;
* can write a CSV report;
* exits non-zero for malformed arguments, malformed inventory, coverage runtime failure, or Go coverage failure.

The script does not:

* enforce thresholds;
* compare against baseline;
* fail on low package coverage;
* fail on Tier 1/Tier 2 coverage percentage;
* change CI workflows;
* change Go code;
* change tests.

## Smoke Validation

Phase 2 smoke validation must run:

```bash
scripts/critical_coverage.sh --help
scripts/critical_coverage.sh
scripts/critical_coverage.sh --report
scripts/critical_coverage.sh --report --csv-output docs/release/v1.10/v1.10.7-phase2-coverage-smoke.csv
```

Expected behavior:

* `--help` prints usage and exits successfully.
* no mode exits with code `2`.
* `--report` completes if tracked package tests pass.
* `--csv-output` writes a CSV report.
* no thresholds are enforced.
