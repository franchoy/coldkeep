# v1.10.3 Phase 5 — Malformed Container Read Safety

Status: Complete

## Purpose

Phase 5 establishes regression test coverage for malformed container read safety.

The expected invariant is:

> VerifyRepository and VerifyRepositoryFast must never panic or silently skip packed-block verification when the container file is missing or truncated. Every read failure must surface as a deterministic, categorised error.

## Scope

Included:

- survey packed container read-failure paths
- validate missing container file produces deterministic error (physical_missing)
- validate truncated container file produces deterministic error (physical_missing)
- confirm no silent-skip behavior on malformed reads
- preserve valid packed-container verification behavior
- focused regression tests for malformed container read scenarios

Excluded:

- compatibility/migration guardrails, Phase 6
- corruption regression matrix consolidation, Phase 7
- GC reachability corrections
- restore/recovery rewrites
- storage format redesign
- engine extraction
- catalog abstraction
- CI workflow changes
- dependency/toolchain changes
- tracker/matrix closure

## Design Rule

Phase 5 validates safe fail-closed behavior only.

Do not expand into broad corrupt-container migration/version guardrails, GC reachability, or restore/recovery work.

## Read-Safety Contract

| Failure mode | Expected error category | No panic | No silent skip |
|---|---|---|---|
| Container file missing (`os.Remove`) | `physical_missing` | ✓ | ✓ |
| Container file truncated (`os.Truncate`) | `physical_missing` | ✓ | ✓ |

## Read-Safety Path Survey

| File | Type / Function | Failure path | Current behavior | Phase 5 action |
|---|---|---|---|---|
| `internal/verify/verify_block_pipeline.go` | `FilesystemContainerReader.ReadStoredPayload` | `container.OpenReadOnlyContainer` error | returns error | verified via integration test |
| `internal/verify/verify_block_pipeline.go` | `VerifyStoredBlock` | `ReadStoredPayload` error | wraps as `physical_missing` | verified via integration test |
| `internal/container/container.go` | `FileContainer.ReadAt` | short read: `int64(n) != size` | returns `"short read"` error | already enforced; confirmed |
