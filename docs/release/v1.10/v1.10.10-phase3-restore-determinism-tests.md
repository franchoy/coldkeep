# v1.10.10 Phase 3 — Restore Determinism Cross-Platform Tests

Status: Complete

## Purpose

Phase 3 adds restore-focused cross-platform determinism tests.

## Core Invariant

Restore behavior must remain byte-deterministic and path-safe across platform-sensitive path forms without claiming unsupported metadata equivalence across Linux, macOS, and Windows.

## Implementation

Phase 3 adds restore tests covering platform-sensitive destination path forms and byte-identical restore output.

## Covered Cases

Phase 3 covers:

- nested relative restore destination paths;
- restore destination paths with dot segments;
- repeated separator path forms;
- parent traversal rejection via pathsafe.SafeJoin guardrail;
- byte-identical restore output for empty, binary, mixed line-ending, and repeated-pattern payloads;
- host-specific path semantics documentation.

## Platform Interpretation

These tests validate host filesystem behavior and platform-sensitive path forms.

They do not claim native Windows semantics until executed on Windows CI.

## Risk Register Updates

- `CK-11010-R11` added: restore byte determinism across platform-sensitive path forms is covered by Phase 3 tests.

## Scope Confirmation

Phase 3 does not:

- change CI;
- change scripts;
- change dependencies;
- claim unsupported Windows/macOS behavior;
- add platform-specific runtime hacks;
- claim metadata equivalence across platforms.
