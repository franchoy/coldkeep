## Release

v1.10.2 — Validation & Security Hardening

## Purpose

Phase 0 creates the control plane for v1.10.2.

This phase defines scope, imports relevant tracker/matrix rows, creates the phase plan, creates the test inventory, records the baseline validation state, and confirms that v1.10.2 remains fixes-only.

Phase 0 does not implement production behavior changes.

## Roadmap Scope

v1.10.2 is scoped to validation and security hardening:

- centralize path normalization
- reject traversal and Windows-drive snapshot paths
- validate container filenames before filesystem joins
- harden restore destination handling
- fix unsafe temp/rename/overwrite patterns
- upgrade Go/toolchain dependencies to eliminate known CVEs

## Strict Exclusions

v1.10.2 does not include:

- engine extraction
- catalog abstraction implementation
- default database backend changes
- daemon/API/UI work
- packed storage metadata integrity work
- GC reachability corrections
- full restore/recovery rewrite
- filesystem fault injection implementation
- Codacy gating policy implementation
- critical-path coverage gates
- new product features
