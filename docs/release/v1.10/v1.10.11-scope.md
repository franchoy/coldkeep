# v1.10.11 — Stabilization & Regression Burn-down Scope

Status: Draft / Phase 0

## Purpose

v1.10.11 is the final stabilization and regression burn-down release before v1.10 behavior is frozen as the baseline for engine-boundary preparation.

This release must reduce remaining release risk without introducing new product features or architecture work.

## Core Invariant

v1.10.11 must close the v1.10 stabilization train without introducing new product features, engine extraction, catalog abstraction, or untracked release risk.

## Goals

v1.10.11 will focus on:

- remaining S0/S1 issue review;
- suppression, accepted-risk, and deferred-risk audit;
- Codacy and scanner finding review;
- long-run, adversarial, and regression suite validation;
- flaky test identification and containment;
- final v1.10 behavior freeze evidence;
- known-issues-after-v1.10 documentation;
- release-candidate readiness.

## Non-Goals

v1.10.11 must not include:

- engine extraction;
- catalog abstraction implementation;
- default database backend changes;
- daemon work;
- API work;
- UI work;
- NAS/cloud/network behavior;
- broad refactors;
- style-only cleanup;
- new product features.

## Allowed Changes

Allowed changes are limited to:

- release-control documentation;
- issue/risk classification;
- test evidence documentation;
- CI/Codacy evidence documentation;
- narrow fixes only if Phase 1+ finds a real S0/S1 bug;
- narrow flaky-test fixes only if evidence proves flakiness.

## Exit Criteria

v1.10.11 can proceed to release only when:

- v1.10.10 release evidence is clean;
- remaining S0/S1 status is known;
- accepted/deferred risks are audited;
- long-run/adversarial/regression validation evidence exists;
- flaky tests are classified or resolved;
- no new unknown release risk remains;
- v1.10 behavior is ready to freeze for v1.10.12 engine-boundary preparation.
