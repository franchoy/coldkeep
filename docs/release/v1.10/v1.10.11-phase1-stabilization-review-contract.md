# v1.10.11 Phase 1 — Stabilization Review Prompt & Scope Contract

Status: Complete

## Purpose

Phase 1 defines the v1.10.11 stabilization review contract and reusable review prompt before issue burn-down begins.

## Core Invariant

v1.10.11 stabilization work must only reduce known release risk, preserve v1.10 behavior, and avoid engine extraction, catalog abstraction, product features, broad refactors, or untracked behavior drift.

## Review Contract Summary

The review contract requires every v1.10.11 change to identify:

- the release risk being reduced;
- the protected invariant;
- severity;
- behavior impact;
- regression evidence;
- compatibility impact;
- packed/legacy impact;
- CLI/JSON/exit-code impact;
- restore/verify/GC/recovery/snapshot/migration impact.

## Scope Boundary

Phase 1 confirms that v1.10.11 must not include:

- engine extraction;
- catalog abstraction implementation;
- daemon work;
- API work;
- UI work;
- NAS/cloud/network behavior;
- default database backend changes;
- broad refactors;
- product features.

## Scope Confirmation

Phase 1 does not change:

- runtime behavior;
- tests;
- CI;
- scripts;
- dependencies;
- repository format;
- container format;
- CLI behavior.
