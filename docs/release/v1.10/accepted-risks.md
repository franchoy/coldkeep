# v1.10 Accepted Risks

Status: Active  
Owner phase: Phase 7 and later

## Purpose

Records real risks that are intentionally accepted with rationale.

Accepted risk is not suppression.

Acceptance means the issue is real but tolerated for a documented reason.

## Required Fields

Every accepted risk must include:

- accepted risk ID
- linked issue ID or matrix ID
- severity
- domain
- reason
- impact
- mitigation
- owner/date
- review condition
- reopen condition
