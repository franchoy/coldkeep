# v1.10.4 Phase 0 — Baseline, Scope & Inventory Refresh

Status: Complete

## Release

v1.10.4 — GC Reachability & Deletion Correctness

## Purpose

Phase 0 creates the control plane for v1.10.4.

This phase defines scope, imports relevant tracker/matrix rows, creates the phase plan, creates the test inventory, records baseline validation, and confirms that v1.10.4 remains fixes-only.

Phase 0 does not implement production behavior changes.

## Release Scope

v1.10.4 is scoped to GC reachability and deletion correctness:

- GC reachability correctness
- snapshot-retained block protection
- logical-file / chunk / block reference integrity
- deletion refusal semantics
- GC dry-run vs destructive-run parity
- physical file deletion safety
- orphan detection correctness
- GC audit/report correctness
- concurrency/mutation guardrails for GC-sensitive operations
- regression tests for unsafe deletion cases

## Strict Exclusions

v1.10.4 does not include:

- packed-storage metadata integrity work completed in v1.10.3
- full restore/recovery rewrite
- Codacy/CI policy implementation
- critical-path coverage gates
- engine extraction
- catalog abstraction implementation
- default database backend changes
- daemon/API/UI work
- NAS/network/cloud expansion
- new product features
