## Release Scope

v1.10.3 is scoped to packed-storage metadata integrity:

- packed container metadata validation
- manifest/index consistency
- packed block metadata validation
- offset/length/bounds validation
- checksum/hash consistency
- corrupt metadata rejection
- safe reads from malformed packed containers
- packed-storage compatibility guardrails
- regression tests for malformed packed-storage metadata

## Strict Exclusions

- GC reachability corrections
- full restore/recovery rewrite
- Codacy/CI policy implementation
- critical-path coverage gates
- engine extraction
- catalog abstraction implementation
- default database backend changes
- daemon/API/UI work
- NAS/network/cloud expansion
- new product features
