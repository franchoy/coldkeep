# Coldkeep v1.10.5 Release Notes

## Release

v1.10.5 - 2026-05-19 — Release Validation Debt Hardening

## Release Type

Fixes-only. No product behavior changes are intended or introduced in this release.

## Summary

v1.10.5 addresses validation debt accumulated during v1.10.x development. The release consolidates gosec baseline triage evidence, Codacy finding workflow hardening, full-suite timeout investigation and classification, local-vs-CI validation boundary clarification, regression matrix construction, tracker/matrix closure accounting, and full local PRE_RELEASE_CHECKLIST.md execution.

No production code is modified. No operator-visible behavior changes. All changes are release documentation and validation evidence.

## Highlights

- gosec baseline captured and triaged: 114 findings, all classified per Phase 3 policy, 0 direct fixes in this release scope, 2 closure rows inherited from v1.10.4
- Codacy finding workflow hardened: Phase 6 policy defines required PR workflow, evidence format, and merge-blocking rules
- full-suite timeout at `TestConcurrentStoreMultiChunkFilesAtomicCompletion` investigated, classified, and documented as boundary (not a regression)
- local-vs-CI validation boundary clarified: Phase 5 policy defines local failure classification, recording requirements, and CI authority
- validation regression matrix constructed and validated: Phase 8 matrix covers Phases 1-7 evidence
- tracker/matrix closure accounting completed: 2 inherited closure rows from v1.10.4, 13 linked issues covered
- full local PRE_RELEASE_CHECKLIST.md execution recorded: all active sections executed, environment-sensitive failures documented
