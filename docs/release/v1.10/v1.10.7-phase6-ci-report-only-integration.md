# v1.10.7 Phase 6 — Optional CI Report-Only Integration

Status: Complete

## Decision

CI report-only integration was added.

## Purpose

Phase 6 adds CI visibility for v1.10.7 critical-path coverage without introducing threshold enforcement.

## Core Invariant

CI integration must provide critical-path coverage visibility without enforcing thresholds, blocking on raw coverage percentages, or changing product behavior.

## Workflow Job

```text
critical-coverage-report
```

## CI Command

```bash
scripts/critical_coverage.sh --report --csv-output docs/release/v1.10/v1.10.7-ci-coverage-report.csv
```

## Artifact

```text
v1.10.7-critical-coverage-report
```

The artifact contains:

```text
docs/release/v1.10/v1.10.7-ci-coverage-report.csv
```

## Report-Only Meaning

The job validates that the report can be generated.

The job does not:

* enforce package coverage thresholds;
* compare coverage against baseline;
* fail because a Tier 1 package is below 75%;
* fail because `internal/maintenance` or `internal/recovery` are low visibility;
* add global coverage gates;
* modify product behavior.

The job may fail if:

* Go tests fail while generating coverage;
* the coverage script fails;
* the inventory is malformed;
* the coverage artifact cannot be produced.

## Local Validation

## Non-Goals

Phase 6 does not:

* add soft-gate or hard-gate script modes;
* enforce thresholds;
* compare coverage against baseline;
* change Go code;
* change tests;
* change dependencies;
* change Codacy behavior.
