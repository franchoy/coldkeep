# v1.10.10 OS Matrix Validation

Status: Initialized

## Purpose

This document records the v1.10.10 GitHub Actions OS matrix validation scope.

## Core Invariant

Cross-platform CI must validate platform-sensitive behavior without weakening Linux coverage, hiding platform failures, or claiming unsupported Windows/macOS behavior.

## Matrix

| OS | Purpose | Scope |
|---|---|---|
| ubuntu-latest | Linux baseline | path safety and restore cross-platform tests |
| macos-latest | macOS feasibility | path safety and restore cross-platform tests |
| windows-latest | Windows feasibility | path safety and restore cross-platform tests |

## Validation Scope

The matrix validates:

- path safety helpers;
- path normalization cross-platform tests;
- metadata policy host-behavior tests;
- restore cross-platform determinism tests.

## Explicit Non-Goals

The matrix does not yet claim:

- full Windows production support;
- full macOS production support;
- Windows-native shell script compatibility;
- benchmark portability;
- complete metadata equivalence;
- complete symlink portability.

## Expected CI Behavior

The matrix should fail if platform-sensitive tests fail on any target OS.

If macOS or Windows exposes a real platform difference, the release must either:

1. fix the behavior safely; or
2. document the platform-specific limitation and adjust the support contract.

## Required Evidence

After PR CI runs, update this document with:

- PR URL;
- workflow run URL;
- matrix result per OS;
- any platform-specific findings.
