## High-Priority Coupling Areas

### runRestoreCommand (CLI-BC-11012-009, CLI-BC-11012-010, CLI-BC-11012-012)

CLI owns the full restore batch pipeline: raw target loading, target preparation, storage context construction, restore execution, output directory creation, and error-to-batch-result mapping. The restore output safety invariant (`ensureRestoreOutputDir` — `os.MkdirAll` + `st.IsDir()` check) is enforced in CLI with no corresponding domain layer.

### runRemoveCommand (CLI-BC-11012-013, CLI-BC-11012-014)

Three dispatch modes (single `--stored-path`, batch `--stored-paths`, fileID batch) with batch orchestration via `batch.ExecutePrepared()`. The dry-run path executes a direct SQL `QueryRow` against `physical_file` in the CLI layer without going through a storage context abstraction.

### runVerifyCommand + collectVerifyOutputSummary (CLI-BC-11012-021, CLI-BC-11012-022)

Verify dispatches to `maintenance.VerifyCommandWithContainersDir()`, but the post-verify summary count query (`collectVerifyOutputSummary`) opens a direct DB connection in the CLI and runs multi-table SQL joins against `storage_blocks` and legacy `blocks` tables.

### runDoctorCommand (CLI-BC-11012-023)

Phase-ordered orchestration: recovery → schema version → verify → system audit. Short-circuits on error. Contains a frozen v1.0 JSON contract with recovery counters that must not be broken. Phase sequencing is entirely CLI-owned with no engine abstraction.

### shouldRunStartupRecovery + runStartupRecoveryWithOptionalLogBuffering (CLI-BC-11012-042, CLI-BC-11012-043)

Correctness-critical: automatic pre-flight recovery runs before store, restore, remove, repair, gc, stats, inspect, list, search, verify, and snapshot. This invariant gate (which may mutate metadata) is implemented entirely in `runCLI()` with no engine contract abstraction.

### createTemporaryBenchmarkDatabase (CLI-BC-11012-027)

Direct PostgreSQL admin `ExecContext` calls for `CREATE DATABASE` and `DROP DATABASE` in the CLI benchmark path. This is the only place in the codebase where CLI-level database administration occurs.
