# v1.10 External Audit Inventory

Status: Pending  
Owner phase: Phase 6 - External Audit Import

## Purpose

Converts the third-party audit issue list into deduplicated root-cause issue families.

The external audit is expected to contribute findings around:

- CLI contract inconsistencies
- JSON output issues
- validation gaps
- restore edge cases
- GC/reachability risks
- packed-storage parity
- benchmark/tooling correctness
- CI/script masking risks
