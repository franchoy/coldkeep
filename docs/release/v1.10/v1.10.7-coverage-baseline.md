## Purpose

This document records the formal v1.10.7 critical-path coverage baseline.

The baseline is evidence, not a pass/fail threshold.

## Baseline Policy

This baseline does not enforce absolute coverage thresholds.

Low coverage in this document is not a release failure by itself.

Coverage becomes actionable when it indicates:

* missing evidence for a correctness invariant;
* malformed or missing coverage artifact;
* unexplained regression from this baseline in a later phase;
* absence of invariant mapping for a Tier 1 package.

## Interpretation

The v1.10.7 baseline is intentionally descriptive.
