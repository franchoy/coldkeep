# v1.10.2 Phase 9 - Go / Toolchain CVE Upgrade

Status: Complete

## Purpose

Phase 9 reviews and remediates Go/toolchain/dependency CVE exposure for v1.10.2.

The expected invariant is:

> Coldkeep must not knowingly ship v1.10.2 with fixable Go/toolchain/dependency CVE exposure.

## Scope

Included:

- record current Go version
- record current module/toolchain directives
- run vulnerability validation
- upgrade Go/toolchain/dependencies only if required
- document no-op decision if no upgrade is required
- run full validation after any dependency/toolchain change
- preserve v1.10.2 behavior

Excluded:

- CI workflow changes
- script argument validation, Phase 10
- storage format changes
- GC behavior changes
- packed-storage behavior changes
- restore/recovery behavior changes
- broad dependency modernization unrelated to CVE remediation
- tracker/matrix closure

## Source Inputs

- `go.mod`
- `go.sum`
- `govulncheck` or equivalent vulnerability validation
- `docs/release/v1.10/v1.10.2-matrix-inventory.csv`
- `docs/release/v1.10/v1.10.2-issue-inventory.csv`
- `docs/release/v1.10/v1.10.2-test-inventory.csv`

Phase 9 should perform minimal security-driven toolchain/dependency remediation only. Do not upgrade dependencies for style, freshness, or preference unless needed to clear vulnerability exposure.
