# Coldkeep v1.10.10 — Cross-Platform Validation

Release date: 2026-05-27

## Summary

v1.10.10 delivers cross-platform validation evidence for Coldkeep — confirming that
correctness-critical behavior is stable across Ubuntu, macOS, and Windows CI runners.

No product behavior was changed. No storage format was changed. No engine contracts were modified.

## What Changed

- Cross-platform tests for path normalization added
- Cross-platform tests for restore determinism added
- Metadata policy for symlinks, permissions, and timestamps documented
- GitHub Actions OS matrix added (ubuntu-latest, macos-latest, windows-latest)
- Script portability boundaries documented
- Local validation evidence captured

## Compatibility

No migration required. Storage format unchanged. All existing repositories remain fully
compatible with v1.10.10.

## Platform support boundary

v1.10.10 validates feasibility on Windows and macOS but does not claim full production support.
The supported production platform remains Linux. Windows and macOS support is a planned
future milestone.

## Known Limitations

- Windows-native shell scripts are not supported (Git Bash / WSL required)
- Permission and timestamp identity across platforms is not guaranteed
- Symlink preservation is not claimed on Windows or macOS

## No migration required

Upgrade from any v1.10.x release does not require any migration steps.
Storage and catalog formats are unchanged.
