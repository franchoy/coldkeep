# v1.10.6 Phase 3 — Critical-Path Coverage Prompt

Status: Complete

## Purpose

Phase 3 adds a critical-path coverage prompt for future Coldkeep coverage work.

The expected invariant is:

> Coverage work must protect Coldkeep's safety-critical behavior, not chase global percentage metrics or style/tooling noise.

## Scope

Included:

- add .github/prompts/critical-path-coverage.prompt.md
- define correctness-first coverage priority order
- define coverage proposal checklist
- define good coverage targets
- define bad coverage anti-patterns
- define required coverage proposal output
- define v1.10.x coverage boundaries
- update v1.10.6 inventories, checklist, and phase status

Excluded:

- adding coverage gates
- changing CI workflows
- changing production code
- changing tests
- changing scripts
- changing dependencies
- adding mutation testing
- adding filesystem fault injection
- adding global coverage thresholds
- tracker/matrix closure
