# v1.10 Release Notes Source of Truth

Status: Complete

## Purpose

This document clarifies the release-notes convention for v1.10.x patch releases.

## Source of Truth

For v1.10.12 and later, release notes are maintained through:

- GitHub Releases;
- `CHANGELOG.md`;
- `docs/release/v1.10/**` release evidence documents.

Root-level `RELEASE_NOTES_v1.10.N.md` files are optional historical
artifacts, not mandatory release gates.

## Decision

v1.10.15 does not backfill root-level `RELEASE_NOTES_v1.10.12.md`,
`RELEASE_NOTES_v1.10.13.md`, or `RELEASE_NOTES_v1.10.14.md`.

The authoritative release notes for those versions are the GitHub Releases
and release evidence documents under `docs/release/v1.10/`.

## Rationale

Duplicating release notes across multiple locations adds maintenance
overhead without improving accuracy. The GitHub release and release evidence
documents already contain the authoritative release information. The
`CHANGELOG.md` provides the cumulative historical record.

## Prior Pattern

`RELEASE_NOTES_v1.10.11.md` exists at the repository root as a historical
artifact from the period when root-level release notes were used. It is
retained for historical continuity but does not establish a requirement for
future releases.

## Non-Goals

This document does not change runtime behavior, release content, storage
behavior, repository format, engine scope, or catalog scope.
