# Coldkeep v1.10.4 Release Notes

## Release

v1.10.4 — GC Reachability & Deletion Correctness

## Release Type

Fixes-only correctness hardening and release-readiness documentation.

## Summary

v1.10.4 consolidates GC reachability and deletion correctness evidence across Phases 1-11 and finalizes release-candidate documentation in Phase 12. The release validates snapshot-retained data protection, logical/chunk/block reference integrity, GC candidate-selection safety, dry-run/destructive parity, physical deletion guardrails, orphan/report correctness, and mutation/concurrency guardrails.

This release does not add product features.

## Highlights

- Documents GC reachability invariants and deletion-safety guardrails across Phases 1-8.
- Confirms consolidated regression evidence for included v1.10.4 matrix rows in Phase 9.
- Finalizes tracker/matrix closure outcomes in Phase 10:
  - CK-110-M014 fixed
  - CK-110-M036 fixed
  - CK-110-M079 fixed
  - 35 linked issue rows closed with explicit v1.10.4 closure proof
- Records Phase 11 local validation boundary evidence for release readiness.
- Finalizes Phase 12 release-candidate artifacts (PR notes, release notes, changelog).

## Compatibility Notes

This release is fixes-only and behavior-preserving with respect to existing GC, snapshot, retention, and restore semantics. It strengthens correctness evidence and release accounting without introducing new runtime behavior.

## Out of Scope

The following remain intentionally out of scope for v1.10.4:

- engine extraction
- catalog abstraction
- new product features
- broad restore/recovery rewrites
- packed-storage metadata feature work
- CI policy changes
