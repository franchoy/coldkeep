# v1.10.10 Copilot Prompt — Cross-Platform Validation

## Mission

Proceed with v1.10.10 cross-platform validation.

The goal is to validate Coldkeep behavior across Linux, macOS, and Windows where feasible, without introducing unsupported platform claims or platform-specific runtime hacks.

## Core Invariant

v1.10.10 must validate and document Coldkeep behavior across supported platforms without claiming unsupported behavior, weakening correctness guarantees, or introducing platform-specific runtime hacks.

## Scope

Focus on:

- path normalization;
- Windows path separators and drive paths;
- restore determinism;
- rename/overwrite semantics;
- symlink behavior;
- permissions;
- timestamps;
- SQLite file behavior;
- line endings;
- shell script portability;
- CI OS matrix feasibility.

## Non-Goals

Do not implement:

- engine extraction;
- catalog abstraction;
- default database changes;
- product features;
- installers;
- GUI;
- cloud/NAS behavior;
- broad runtime rewrites;
- randomized chaos;
- mutation testing.

## Safety Rules

- Prefer tests and documentation before runtime changes.
- Do not claim Windows/macOS support beyond what CI validates.
- Do not weaken Linux behavior to satisfy another platform.
- Do not introduce platform-specific hacks unless there is a correctness reason and it is documented.
- Keep every phase narrowly scoped.

## Recommended Phase Shape

1. support contract and prompt;
2. path normalization tests;
3. restore determinism tests;
4. symlink / permissions / timestamp policy;
5. GitHub Actions OS matrix;
6. script portability audit;
7. local and CI validation;
8. PR / CI / Codacy / merge / release.

## Required Evidence

Each phase should update:

- phase status;
- checklist;
- release evidence document;
- any relevant platform matrix or risk register.
