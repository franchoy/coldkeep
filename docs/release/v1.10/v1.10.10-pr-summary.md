# v1.10.10 — Cross-Platform Validation

## Summary

This PR delivers v1.10.10 — the cross-platform validation release for Coldkeep.

v1.10.10 adds cross-platform validation evidence across Ubuntu, macOS, and Windows without
changing product behavior, engine contracts, or storage formats.

## Changes

- Path normalization cross-platform tests added (Phase 2)
- Restore determinism cross-platform tests added (Phase 3)
- Symlink, permissions, and timestamp metadata policy documented (Phase 4)
- GitHub Actions OS matrix added targeting ubuntu-latest, macos-latest, and windows-latest (Phase 5)
- Script portability audit completed and boundaries documented (Phase 6)
- Local validation completed across targeted test packages (Phase 7)
- Release documentation, phase status, and risk register complete

## Scope Boundary

This PR does not claim full Windows/macOS production support. The OS matrix validates
correctness-critical behavior — path safety and restore determinism — as a feasibility baseline.
Full Windows production support is deferred to a future release.
