# v1.10.11 Regression Matrix

Status: Phase 5 complete

## Purpose

This document defines the v1.10.11 regression matrix — the complete set of validation gates that must pass before v1.10.11 is eligible for release candidate promotion.

The matrix ensures:

- No correctness invariant regresses between v1.10.10 and v1.10.11.
- All deferred, accepted, and suppressed risk items from Phase 3 remain visible.
- All cross-platform, long-run, and adversarial surfaces are explicitly tracked.
- Release-blocking gaps are identified before Phase 8 (Release Candidate Gate).

The matrix is not a pass/fail log. It is a definition. Execution and results are recorded in Phase 5.

## Required Local Gates

The following gates must pass locally before a PR is opened for v1.10.11:

```bash
# 1. Baseline unit tests with race
go test -race -count=1 ./cmd/... ./internal/...

# 2. Static analysis
go vet ./...

# 3. Restore path safety
go test ./internal/storage -run "RestoreCrossPlatform|RestoreSeam" -count=1

# 4. GC reachability
go test -race -count=1 ./internal/maintenance ./internal/gc

# 5. Verify fail-closed
go test -race -count=1 ./internal/verify

# 6. Snapshot retention
go test -race -count=1 ./internal/snapshot

# 7. Recovery correctness
go test -race -count=1 ./internal/recovery

# 8. Path safety
go test ./internal/pathsafe/... -count=1

# 9. Packed/legacy parity
go test -race -count=1 ./internal/maintenance -run "Parity|Packed|Step11"

# 10. Filesystem fault injection
go test -race -count=1 ./internal/maintenance -run "FaultFS|Faultfs"

# 11. CLI/JSON contracts
go test -race -count=1 ./internal/cli/... ./cmd/...

# 12. Coverage gate
bash scripts/critical_coverage.sh

# 13. Adversarial invariants
go test -race -count=1 ./tests/adversarial/...

# 14. Integration
go test -race -count=1 ./tests/integration/...

# 15. Long-run soak
go test -race -count=1 ./tests/integration/... -run 'TestStoreGCVerifyRestoreDeleteLoopStability|TestRandomizedLongRunLifecycleSoak|TestSnapshotRetentionChurnLongRun'

# 16. Release validation scripts
bash scripts/validate_validation_matrix.sh

# 17. Race over test suites
go test -race -count=1 ./tests/adversarial/... ./tests/integration/...
```
