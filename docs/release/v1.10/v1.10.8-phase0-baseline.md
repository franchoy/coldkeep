# v1.10.8 Phase 0 — Baseline & Scope Declaration

Status: Complete

## Purpose

Phase 0 establishes the release-control baseline for v1.10.8.

v1.10.8 is the filesystem abstraction groundwork release. Its purpose is to prepare safe, deterministic filesystem seams for future v1.10.9 fault injection work while preserving current behavior.

## Core Invariant

v1.10.8 must prepare filesystem abstraction seams for future deterministic fault injection while preserving current storage, restore, container, recovery, snapshot, and GC behavior exactly.

## Baseline Assumption

v1.10.8 starts after v1.10.7 is released and merged into `main`.

v1.10.7 introduced critical-path coverage visibility, formal baseline evidence, invariant coverage mapping, soft threshold policy, report-only CI integration, regression-prevention design, and pre-PR quality validation.

v1.10.8 builds on that release-control foundation.
