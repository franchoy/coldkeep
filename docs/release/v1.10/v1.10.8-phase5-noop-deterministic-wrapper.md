# v1.10.8 Phase 5 — No-Op Deterministic Wrapper

Status: Complete

## Purpose

Phase 5 implements a no-op deterministic wrapper around `fsx.FS`.

The wrapper prepares an explicit seam for future deterministic wrappers while preserving behavior exactly in v1.10.8.

## Core Invariant

The no-op deterministic wrapper must preserve wrapped filesystem behavior exactly and must not inject, transform, retry, suppress, reorder, or reinterpret filesystem operations.

## Implementation

Phase 5 adds:

```text
internal/fsx/noop.go
internal/fsx/noop_test.go
```

## Wrapper

The package implements:

* `NoopFS`
* `NewNoop`

`NoopFS` delegates directly to the wrapped `FS`.

## Behavior Preservation

The wrapper must not:

* rewrite paths;
* normalize errors;
* retry operations;
* swallow errors;
* reorder operations;
* add fault injection;
* change permissions;
* change sync behavior;
* change traversal behavior.

## Tests

* missing-path error preservation through `NewNoop(Default())`.
