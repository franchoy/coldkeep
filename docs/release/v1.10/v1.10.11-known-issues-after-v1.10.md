## Accepted Risks

Accepted risks are not hidden. They are intentionally visible and carried forward
with rationale.

### KI-11011-001 — Dependencies / Go toolchain CVE baseline

**Source:** CK-11011-S1-009

**Summary:** go.mod specifies go 1.25 with toolchain go1.25.10, which is an
actively maintained toolchain release. No individual CVE within the 46-finding
M009 scanner grouping has been confirmed to affect coldkeep-specific code paths.

**Carried to:** v1.10.12+

**Rationale:** Toolchain upgrade is tracked for v1.10.12+. Maintained toolchain
version represents the appropriate mitigation posture for scanner-sourced
vulnerability groupings.

### KI-11011-002 — Benchmark / exec.Command

**Source:** CK-11011-S1-014

**Summary:** `exec.Command` in `defaultCommandRunner()` (`internal/benchmark/scenarios.go`
line 441) uses `spec.Executable` sourced from configuration-time values, not
untrusted user CLI input at runtime. The benchmark package is not a production
data path.

**Carried to:** none

**Rationale:** Code review confirmed no route from untrusted user input to
`spec.Executable`. Accepted permanently; no future tracking needed.

## Suppressed Findings

Suppressed findings must include rationale and evidence. They are not hidden —

### KI-11011-003 — Security / Dynamic SQL scanner false positives

**Source:** CK-11011-S1-010

**Summary:** 3 dynamic SQL scanner findings suppressed after code review:

- CK-110-0013 and CK-110-0040 (`internal/observability/stats.go`): `fmt.Sprintf`
  used only to construct positional `$N` placeholder strings (e.g.
  `fmt.Sprintf("$%d", i+1)`). Values are positional integers, not user data.
  Query executed with `s.db.QueryContext(ctx, query, args...)` with bound args.
- CK-110-0014 (`internal/repository/capabilities/derive.go`): `PRAGMA table_info(%s)`
  where `tableName` is sourced exclusively from compile-time application schema
  constants. SQLite PRAGMA does not accept parameterized identifiers; `fmt.Sprintf`
  is the only valid approach for this read-only schema introspection.

**Carried to:** none

**Rationale:** All 3 confirmed scanner false positives after code review.
