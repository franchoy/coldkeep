# v1.10.10 Phase 4 — Symlink / Permissions / Timestamp Policy

Status: Complete

## Purpose

Phase 4 defines Coldkeep's policy for platform-sensitive filesystem metadata.

## Core Invariant

Coldkeep must not overclaim metadata equivalence across Linux, macOS, and Windows. Symlink, permission, timestamp, and case-sensitivity behavior must be tested where safe and documented where platform-dependent.

## Implementation

Phase 4 adds:

```text
docs/release/v1.10/v1.10.10-symlink-permission-timestamp-policy.md
internal/pathsafe/metadata_policy_crossplatform_test.go
```

### Metadata Policy Tests Added

Four lightweight policy tests in `internal/pathsafe/metadata_policy_crossplatform_test.go`:

- `TestMetadataPolicyDoesNotAssumeGlobalCaseSensitivity` — observes host case-sensitivity behavior without asserting universal semantics; graceful on case-insensitive filesystems
- `TestMetadataPolicyTreatsPermissionBitsAsHostDependent` — verifies non-zero permissions on host; documents Linux behavior without cross-platform claims
- `TestMetadataPolicyTreatsTimestampsAsHostDependent` — verifies non-zero mtime on host; documents Linux behavior without cross-platform claims
- `TestMetadataPolicyDoesNotUseSymlinkAssumption` — observes host symlink behavior; graceful skip if symlink creation is unavailable

## Policy Areas Covered

- symlink behavior;
- permission behavior;
- timestamp behavior;
- case-sensitivity behavior;
- host filesystem metadata semantics.

## Actual Metadata Behavior Documented

Coldkeep stores and restores `mode`, `mtime`, `uid`, and `gid` on Linux. The `--no-metadata` flag skips restoration. The `--strict` flag requires metadata to be complete. Symlinks are resolved at store time and rejected at restore time via `pathsafe`. Cross-platform equivalence on macOS and Windows is not tested in v1.10.10.

## Release Claim Boundary

v1.10.10 may claim:

- byte-identical restore for tested restore paths;
- path safety for tested path validation paths;
- permission and timestamp restoration on Linux where metadata is complete;
- documented limitations for metadata-sensitive behavior.

v1.10.10 must not claim:

- portable symlink preservation;
- POSIX permission equivalence on Windows;
- timestamp identity across platforms;
- universal case-sensitive path behavior;
- full Windows/macOS production support beyond what CI proves.
