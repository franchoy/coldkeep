# v1.10.10 Scope

Status: Draft

## Release

v1.10.10 - Cross-Platform Validation

## Core Invariant

v1.10.10 must strengthen correctness evidence across Linux (Ubuntu), macOS, and Windows without changing repository format, CLI/JSON contracts, or introducing product features.

## Included

- Cross-platform validation for path normalization behavior.
- Cross-platform validation for restore determinism.
- Cross-platform validation for symlink policy behavior where supported.
- Cross-platform validation for permissions and timestamps handling with explicit platform limitations.
- Cross-platform CI evidence capture in release documentation.

## Excluded

- Engine extraction.
- Catalog abstraction.
- Default database backend changes.
- Product features.
- Broad refactors.
- Repository or container format changes.

## Guardrails

- Correctness and determinism are release-blocking; style findings are not.
- PostgreSQL compatibility must remain tested.
- Platform limitations must be documented explicitly, not implied.
- Do not claim full platform support without CI evidence.

## Release Gate Intent

v1.10.10 release closure requires successful CI evidence on Linux (Ubuntu), macOS, and Windows.
