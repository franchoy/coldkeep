## CI Stability Notes

**Workflow trigger boundary:** `ci.yml` triggers on push to `main`,
`release/**`, `hotfix/**`, tags, and PRs to `main`. Feature branches do not
trigger CI unless a PR is opened. No remote CI runs exist for
`feature/v1.10.11-stabilization-regression-burndown` (`gh run list` returned
empty).

**Local vs CI environment gaps (accepted observations):**

- `COLDKEEP_LONG_RUN=1` — CI `integration-long-run` and `adversarial` jobs set
  this variable; local Phase 5 runs did not. Local adversarial completed in ~1s
  versus up to 60-min CI timeout, confirming the short path was used locally.
  This is expected. CI coverage is pending Phase 9.

- PostgreSQL — CI `correctness-matrix`, `integration-stress`,
  `integration-long-run`, and `adversarial` jobs run with a PostgreSQL 16
  service container. Local Phase 5 used SQLite (default). Full PostgreSQL
  coverage is pending Phase 9.
