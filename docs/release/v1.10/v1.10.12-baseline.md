# v1.10.12 Baseline

Status: Complete

## Baseline

v1.10.12 starts from released v1.10.11 on main.

## Purpose

v1.10.12 is the final readiness step before v1.11 engine-boundary work.

## Baseline Guarantees

v1.10.11 provided:

- S0/S1 risk inventory;
- risk disposition audit;
- regression matrix;
- local validation results;
- flaky/CI stability audit;
- known-issues-after-v1.10 handoff;
- release-candidate gate;
- final release evidence.

## v1.10.12 Boundary

v1.10.12 may identify contracts, inventories, maps, and transition rules.

v1.10.12 must not implement:

- engine extraction;
- catalog abstraction;
- default database backend changes;
- runtime behavior changes;
- repository format changes;
- CLI behavior changes;
- JSON contract changes.

## v1.11 Handoff Goal

At the end of v1.10.12, v1.11 should have enough evidence to start a behavior-preserving engine facade without hiding unstable semantics behind a new API boundary.
