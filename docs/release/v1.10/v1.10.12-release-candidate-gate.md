## Release Candidate Decision

v1.10.12 is release-candidate ready for Phase 10 PR / CI / Codacy / Merge /
Release handling.

## What v1.10.12 May Claim

v1.10.12 may claim:

- engine-boundary readiness evidence is complete;
- v1.11 transition checklist is prepared;
- no-behavior-change migration guardrails are documented;
- SQLite/PostgreSQL assumptions are documented;
- v1.11 can start with explicit scope and release blockers.

## What v1.10.12 Must Not Claim

v1.10.12 must not claim:

- engine extraction started;
- engine facade implemented;
- CLI decoupled from business logic;
- catalog abstraction implemented;
- SQLite-first behavior implemented;
- PostgreSQL compatibility changed or removed;
- runtime behavior changed;
- release is complete before Phase 10 PR/CI/merge/release evidence exists.

## Phase 10 Requirements

Phase 10 must record:

- PR number;
- PR URL;
- PR CI result;
- Codacy review status;
- merge commit;
- main CI result;
- tag commit;
- GitHub release URL;
- published timestamp.

## Release Boundary

This release-candidate gate does not publish v1.10.12.

This release-candidate gate does not create a tag.

This release-candidate gate does not merge the branch.

This release-candidate gate only declares readiness to enter Phase 10.
