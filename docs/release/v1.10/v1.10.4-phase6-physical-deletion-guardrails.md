## Physical Deletion Guardrail Contract

### Candidate Rules

- Physical deletion may target only validated destructive GC candidates.
- Physical deletion must not recompute a broader candidate set than dry-run/candidate selection.
- Protected live, retained, shared, or ambiguous data must never reach physical deletion.

### Path Ownership Rules

- Physical deletion targets must be inside Coldkeep-managed storage roots.
- Path traversal or absolute-path escape must be rejected or impossible by construction.
- Deletion must not use untrusted path fragments without containment validation.
- Deletion must not remove parent directories outside the managed storage scope.

### Missing / Partial Failure Rules

- Missing physical files must produce deterministic reporting.
- Missing physical files must not cause deletion of unrelated data.
- Partial deletion failures must be reported clearly.
- Metadata cleanup after deletion must not claim success if physical deletion failed.

### Destructive Safety Rules

- Destructive GC must perform final safety checks before deletion.
- Deletion must be scoped to files/containers selected by GC.
- Directory-wide deletion must be avoided unless explicitly bounded and tested.
