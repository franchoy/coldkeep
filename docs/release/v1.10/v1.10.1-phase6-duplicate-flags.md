# v1.10.1 Phase 6 — Duplicate Singleton Flags

Status: Complete

## Purpose

Phase 6 fixes CLI behavior where singleton flags can appear multiple times without a deterministic policy.

The expected invariant is:

> Duplicate singleton flags must be rejected or explicitly defined.

For v1.10.1, the policy is:

> Duplicate singleton flags are rejected.

## Scope

Included:

- singleton value flags repeated multiple times
- singleton boolean flags repeated multiple times
- deterministic duplicate-flag error behavior
- validation before stateful work where practical
- regression tests for affected command families

Excluded:

- unexpected positional argument handling, already covered by Phase 3
- value-flag token handling, already covered by Phase 4
- boolean explicit false handling, already covered by Phase 5
- JSON shorthand behavior
- JSON output contract behavior
- storage, GC, packed-storage, restore/recovery internals
- CI workflow changes
- dependency/toolchain changes

# Implementation Summary

Phase 6 enforces deterministic duplicate rejection for singleton flags at parse time.

| Command / Family | Flag(s) | Change | Test coverage |
|---|---|---|---|
| CLI parser (`parseCommandLine`) | singleton value flags (for example `--limit`) | duplicate occurrences are rejected with deterministic usage error `duplicate singleton flag: --<flag>` | `TestParseCommandLineRejectsDuplicateSingletonValueFlag` |
| CLI parser (`parseCommandLine`) | singleton boolean flags (for example `--force`) | duplicate occurrences are rejected regardless of bare or `=true/false` form | `TestParseCommandLineRejectsDuplicateSingletonBooleanFlag` |
| CLI parser (`parseCommandLine`) | boolean alias pairs (`--dry-run` / `--dryRun`, `--fail-fast` / `--failFast`) | aliases are canonicalized so mixed-form duplicates are rejected deterministically | `TestParseCommandLineRejectsDuplicateSingletonAliasFlags` |
| CLI parser (`parseCommandLine`) | repeatable flags (`--delete-snapshot`, `--path`, `--prefix`) | repeatable behavior is preserved; multiple values remain accepted | `TestParseCommandLineTreatsDeleteSnapshotAsValueFlag`, `TestParseCommandLineAllowsRepeatableSnapshotQueryFlags` |
