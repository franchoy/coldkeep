# v1.10.3 Phase 3 — Offset / Length / Bounds Validation

Status: Complete

## Purpose

Phase 3 implements packed-storage offset, length, and bounds validation.

The expected invariant is:

> Packed-storage offset, length, and bounds metadata must be validated before any read, seek, allocation, or payload comparison depends on it.

## Scope

Included:

- survey packed offset/length fields
- survey read/seek/allocation paths that use offset/length metadata
- reject negative offsets
- reject invalid lengths
- reject integer overflow in `offset + length`
- reject ranges beyond container/object size
- define zero-length payload semantics
- ensure invalid bounds fail before reads
- preserve valid existing packed container behavior
- focused regression tests for bounds validation

- hash/checksum consistency implementation, Phase 4
- broad malformed container read-safety matrix, Phase 5
- compatibility/migration guardrails, Phase 6
- corruption regression matrix consolidation, Phase 7
- GC reachability corrections
- restore/recovery rewrites

## Offset / Length / Bounds Validation Contract

### Offset Rules

- Offset values must be non-negative.
- Offset values must be measured relative to the expected container/object boundary.
- Offset values must be validated before `ReadAt`, `Seek`, slicing, or allocation.

### Length Rules

- Length values must be non-negative.
- Positive payloads must have positive lengths.
- Zero length is valid only for explicitly allowed empty payload semantics.
- Length values must be validated before allocation or read.

### Range Rules

- `offset + length` must not overflow.
- `offset + length` must not exceed the container/object size.
- A range ending exactly at container/object size is valid.
- A range starting at container/object size is valid only when length is zero and empty payloads are allowed.

### Error Behavior

- Invalid ranges fail deterministically before data reads.
- Invalid ranges must not panic.
- Invalid ranges must not cause unbounded allocation.
- Invalid ranges must not silently skip verification.
