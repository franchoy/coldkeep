# v1.10 Deferred Issues

Status: Active  
Owner phase: Phase 7 and later

## Purpose

Records real issues intentionally moved outside their first assigned release target.

Deferred does not mean ignored.

## Required Fields

Every deferred issue must include:

- deferred decision ID
- linked issue ID or matrix ID
- original target
- new target
- severity
- reason for deferral
- risk during deferral
- mitigation
- owner/date
- follow-up condition

## Current Deferred Issues

No deferred issues recorded during Phase 7 unless manual matrix review explicitly retargeted a row.

Most deferral decisions should occur during release-specific remediation phases.
