# v1.10.10 Phase 5 — GitHub Actions OS Matrix

Status: Complete

## Purpose

Phase 5 adds a minimal GitHub Actions OS matrix for cross-platform validation.

## Core Invariant

Cross-platform CI must validate platform-sensitive behavior without weakening Linux coverage, hiding platform failures, or claiming unsupported Windows/macOS behavior.

## Implementation

Phase 5 adds a dedicated cross-platform validation job to GitHub Actions.

The matrix targets:

- ubuntu-latest;
- macos-latest;
- windows-latest.

## Validation Scope

The matrix runs focused tests for:

- path safety;
- path normalization;
- metadata policy host semantics;
- restore cross-platform determinism.

## Release Claim Boundary

This phase does not claim full Windows/macOS production support.

It only adds CI validation for the targeted path and restore test surfaces.

## Risk Register Updates

Updated risks:

- CK-11010-R13 (all, ci-os-matrix): pending_ci — introduced by Phase 5; final status requires PR CI evidence.

## Scope Confirmation

Phase 5 does not:

- change runtime behavior;
- change scripts;
- change dependencies;
- claim full Windows support;
- claim full macOS support;
- make benchmark scripts Windows-native.

## Validation

Local validation:

```text
go test ./internal/pathsafe/... -count=1
go test ./internal/storage -run "RestoreCrossPlatform|RestoreSeam" -count=1
go test ./...
go vet ./...
```

Remote validation is completed by PR CI after the branch is pushed.
