# v1.10.5 Phase 3 — Gosec Baseline Triage

Status: Complete

## Purpose

Phase 3 triages the baseline-wide `gosec` findings identified during the v1.10.4 Pre-PR Code Quality / Codacy-Risk Gate.

The expected invariant is:

> gosec findings must be classified, not ignored; v1.10.5 should close or defer them with explicit rationale.

## Scope

Included:

- capture a fresh `gosec ./...` baseline
- convert findings to a triage CSV
- classify findings by rule, path, severity, confidence, and release relevance
- identify release-delta findings versus baseline-wide findings
- select only low-risk/high-confidence fixes if any are appropriate
- document deferrals with explicit rationale
- update v1.10.5 test inventory, phase status, and checklist

Excluded:

- broad security refactor
- unrelated style cleanup
- CI workflow changes
- dependency/toolchain changes
- tracker/matrix closure
- fixing every gosec finding in one release
- changing production behavior unless a targeted finding is selected for immediate remediation

## Source Inputs

- v1.10.4 Pre-PR Code Quality / Codacy-Risk Gate
- fresh `gosec ./...` output
- `docs/release/v1.10/v1.10.5-gosec-baseline.csv`
- changed-file diff against `origin/main`

## Design Rule

Phase 3 is triage-first.

Fix only real, low-risk, high-confidence findings that are clearly within v1.10.5 scope. Document all other findings as baseline/deferred/false-positive/tooling-context with rationale.
