# v1.10.6 Scope — CI / Codacy / Copilot Workflow Hardening

## Included

v1.10.6 includes process/tooling hardening for:

- CI observability
- Codacy passive-mode policy
- Codacy finding classification
- scanner suppression/acceptance/defer policy
- Copilot CI instructions
- critical-path coverage prompt groundwork
- release-gate boundary documentation
- workflow consistency validation

## Excluded

v1.10.6 excludes:

- product behavior changes
- production code fixes unless a release-blocking tooling/security issue requires it
- test implementation changes unless strictly required for policy validation
- engine extraction
- catalog abstraction
- default DB behavior changes
- SQLite-only assumptions
- PostgreSQL compatibility removal
- CodeRabbit adoption
- mutation testing
- filesystem fault injection implementation
- cross-platform implementation
- broad cleanup
- style-only blocking

## Rationale

The v1.10 roadmap assigns v1.10.6 to CI Evolution Phase 1 and Codacy Passive Integration.

The Copilot workflow material is included only because it supports the same goal: improving release discipline, Codacy triage, and CI correctness focus without changing product behavior.
