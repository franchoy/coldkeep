# v1.10.6 Phase 5 — Scanner Suppression / Acceptance Policy

Status: Complete

## Purpose

Phase 5 defines scanner suppression, acceptance, deferral, duplicate, baseline, and false-positive policy for v1.10.6.

The expected invariant is:

> Scanner findings must never be silently ignored; every finding must have a decision, rationale, and release impact classification.

## Scope

Included:

- document scanner decision categories;
- document release impact classifications;
- define suppression rules;
- define acceptance rules;
- define deferral rules;
- define false-positive rules;
- define required release evidence;
- define prohibited practices;
- update v1.10.6 checklist, phase status, and test inventory.

Excluded:

- changing scanner configuration;
- changing Codacy configuration;
- changing CI workflows;
- adding suppressions to code;
- changing production code;
- changing tests;
- changing scripts;
- changing dependencies;
- tracker/matrix closure;
- CodeRabbit adoption.

## Source Inputs

- v1.10.6 Phase 4 Codacy passive-mode policy;
- v1.10.5 gosec baseline triage;
- v1.10.5 Pre-PR Code Quality / Codacy-Risk Gate experience;
- Coldkeep release discipline and Codacy workflow direction.

## Implementation Decision

Phase 5 is policy-only.

No scanner configuration, CI workflow, production code, test, script, or dependency changes are made.
