## Critical Access Surfaces

The following 13 surfaces are `critical` risk and must be treated as correctness invariants by any future engine/catalog boundary work:

| ID | Area | Symbol | Invariant |
|---|---|---|---|
| DBFS-11012-001 | DB Connection | `ConnectDB()` | All DB operations begin here; schema init must succeed before any other access |
| DBFS-11012-002 | GC | `RunGCWithContainersDirResult()` | Advisory lock + reachability check before any DELETE; must never delete reachable data |
| DBFS-11012-006 | Restore | `RestoreFileWithStorageContextResultOptions()` | Chunk pinning before restore; atomic temp+rename pattern; must not write outside destination |
| DBFS-11012-009 | Store | `StoreFileWithStorageContextAndCodecResultWithPolicy()` | All logical_file + chunk rows committed before returning; no partial stores |
| DBFS-11012-010 | Snapshot | `CreateSnapshotWithOptions()` | Single transaction covers all snapshot metadata; no partial snapshots |
| DBFS-11012-019 | Recovery | `SystemRecoveryWithContainersDir()` | Must not legitimize corrupt mappings; quarantine is fail-closed |
| DBFS-11012-024 | Filesystem | `restoreFileWithDBAndDir()` | fsync before close; atomic rename to final path; no overwrite of non-temp target |
| DBFS-11012-025 | Filesystem | `AppendPayload()` | fsync on error + Truncate before DB commit; container payload durability |
| DBFS-11012-026 | Filesystem | GC container deletion | File removed only after DB row committed; if remove fails after commit, row is already gone |
| DBFS-11012-031 | Storage Context | `OpenLocalStorage()` | Recovery runs before context opens; no DB access before recovery completes |
| DBFS-11012-034 | Container | `FinalizeContainer()` | fsync + close before next append; durability gate for container sealing |
| DBFS-11012-035 | Transaction | GC per-container transaction scope | Each container deleted in its own transaction; crash during one does not corrupt others |
| DBFS-11012-036 | Transaction | CreateSnapshotWithOptions transaction | All-or-nothing; commit failure leaves no partial snapshot rows |
